# docs/project

Prosjektdokumentasjon, gruppert etter type.

| Mappe | Innhold |
|---|---|
| `plans/` | Implementerings- og forskningsplaner |
| `status/` | Statusrapporter og handover-notater |
| `analysis/` | Analyser, matriser og datakvalitets-gjennomganger |
| `reference/` | Oppsett, drift, prosess og prosjektoversikt |
| `mandates/` | Food TG-mandat, beslutninger, dossiers og kildearbeid (egen README) |
| `forsyningskjede-country-packs/` | Forsyningskjede-underlag per land (egen README) |

Ny spec→plan-arbeidsflyt for nye features ligger i `docs/superpowers/{specs,plans}`,
ikke her.

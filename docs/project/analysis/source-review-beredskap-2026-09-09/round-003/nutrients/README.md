# C3: Gjenvunnet fosfor til faktisk jordbruk

Datert kandidattillegg, 9. september 2026. `NEW-NPK-01` er avgrenset til Hias-struvitt og fosfor. [findings.json](findings.json) inneholder fire kildeversjoner, seks observasjoner, kjedemodell, seks åpne gap og to testbare oppdrag. Ingen originalhistorikk, database, kanoniske data eller readiness er endret.

Hias rapporterte 24 424 kg produsert struvitt i 2024, tilsvarende rapporterte 2 931 kg P. Årsproduksjon er ikke disponibel beholdning eller levert, plantetilgjengelig P. Se [Hias årsrapport, s. 28](https://www.hias.no/getfile.php/133754-1747294746/HIAS/Dokumenter/B%C3%A6rekrafts-%20og%20%C3%A5rsrapporter/2024%20b%C3%A6rekrafts-%20og%20%C3%A5rsrapport%20Hias%20IKS.pdf#page=28).

Gjødselvirkningen må knyttes til produkt, vekst og baseline. [NIBIOs byggforsøk, tabell 10, s. 22](https://www.hias.no/getfile.php/133034-1711021970/HIAS/Dokumenter/Avl%C3%B8p/nibio_rapport_struvitt.pdf#page=22) måler samlet overjordisk tørrstoff i potter, ikke kornavling. [Tingvoll-forsøket, s. 20](https://www.hias.no/getfile.php/133031-1711021760/HIAS/Bilder/Avl%C3%B8p/NORS%C3%98K%20RAPPORT%2010%20struvitt%20FINAL%20Sept%205%202019%20trykk.pdf#page=20) viser betydningen av eksisterende husdyrgjødsel. Rapportens prosentpåstand og doseenhet har interne avvik, registrert i `R3-NPK-O006`. [Hias-deklarasjonen](https://www.hias.no/avlop/struvitt/) gjelder produktinnhold; den kan ikke brukes som feltopptak eller kombineres ukritisk med årsrapportens næringsandel.

Det nasjonale bidraget er ett historisk norsk produksjonseksempel og to forsøk. Ekstra nordisk bidrag er ukjent. Ekstra sirkulært bidrag må måles som funksjon utover eksisterende gjødsel-/slamanvendelse, med tap og faktisk unngått mineralvare.

Neste oppdrag er én mottakerbundet byggtest med partidata, jordprøve, gjødslingsjournal og leveringsfrist; deretter en eventuell paret nordisk sammenligning. Begge er analytiske forslag. Valg av mottaker, forsøk og partner er ikke registrert som beslutninger.

Åpent søk avsluttes ved operatør-/målegapet: sammenbundet aktuelt parti → mottaker → anvendelse → substitusjon mangler. Mer generell litteratur fyller ikke dette. Private PDF-/HTML-originaler, tekstuttrekk, bilder og innhentingskvitteringer er bevart utenfor repo. SHA-256, eksakte lokatorer og faktisk leseomfang ligger i JSON-filen. `verification.json` dokumenterer integritets- og strukturkontroller; den er ikke ekstern faglig attestasjon.

## Hva analysen endrer

2018 kan brukes som konkret samtidig-sjokk-case for C1/C5. Avlingsstudien viser nord-/østeuropeisk samtidighet og søreuropeisk motvekt. Tallet «nær 40 prosent» gjelder arealandel under 10-persentilen, ikke prosent avlingstap. [Beillouin mfl. 2020](https://doi.org/10.1098/rstb.2019.0510).

Nordisk vannføring viser både felles belastning og regional forskjell. De 68 prosentene gjelder utvalgte stasjoner, ikke tapt vannkraft eller leveringskapasitet. Junitallet er inkonsistent mellom resultat og konklusjon (46/43 prosent) og holdes tilbake. [Bakke mfl. 2020](https://doi.org/10.5194/hess-24-5621-2020).

Svenske kornavlinger støtter at varme må vurderes sammen med vannforhold. Den høye modellforklaringen inkluderer tilfeldige år/fylke-effekter; den skal ikke gjengis som klimas isolerte forklaring. Studien er Sverige-avgrenset. [Tootoonchi mfl. 2026](https://doi.org/10.5194/bg-23-2583-2026).

## Kobling til oppdraget

Node → mathveteflyt → delt klima/vann og mulige felles energi-/ruteavhengigheter → 2018-sjokk → nasjonal versus nordisk leveranse → ekstra godkjente tonn innen frist. Bare eksponeringsleddet har nye observasjoner. Faktisk flyt, anleggskvalitet, kontraktert bistand og utfall er eksplisitt ukjent.

- P1: samtidig produksjons- og hydrologisk belastning er nå kildebelagt innen avgrensning.
- P2: norsk reserve, mølle og allokering må være målt baseline.
- P3: nordisk alternativ må ha disponibelt volum også ved eget tap; samme sjokk kan ramme begge.
- P4: C2/C3/C4 må testes for felles vann-, energi- og råvarebortfall; sirkulær tilleggseffekt er ikke demonstrert.
- P5: C1/C5 får testbar hendelse og stoppregel; ingen fem ferdig dokumenterte investeringstiltak.

## Presis restliste og kontroll

1. Harmoniserte region×år×vekst-serier med volum, kvalitet, egenbehov og eksportabel mengde før korrelasjon/nytteberegning.
2. Navngitte møller og ruter med tidsbundet vann, kraft, drivstoff, tørking og faktisk levering. Naturlig vannføring kan ikke erstatte dette.
3. Paret nasjonal/nordisk test ved samme mottaker, kvalitet og frist, inkludert allokering under samtidig behov.

# Institusjonsmåltider: avgrenset øvelsesbevis og målegap

Datert tillegg 9. september 2026. Intern kandidatbasert analyse av C4 / NEW-MEAL-01. Fem primærkilder er åpnet, bevart privat og lest i angitt omfang. Ingen historikk, kanonisk data, menneskelig review eller readiness er endret.

De nye kildene flytter spørsmålet fra bare veiledning til to konkrete, operatørrapporterte øvelsesutfall: [Hylte](https://www.hylte.se/nyheter/nyhetsarkiv/2025-04-22-val-genomford-krisovning-matforsorjning-testades-utan-el-och-rinnande-vatten) oppgir ett måltid for 180 personer, og [Trelleborg](https://www.trelleborg.se/nyheter/beredskapsovning-resulterade-i-en-annorlunda-lunch/) 100 tilberedte porsjoner suppe. Tallene må ikke summeres, omregnes til døgnkapasitet eller kalles dokumentert ernæringsmessig egnet konsum. Hyltes fire timer er et mål; faktisk serveringstid mangler. Øvelsesdatoen har en uløst ukedag/dato-motsigelse. Trelleborgs separate vannøvelse dokumenterer ikke samtidighet for suppeøkten.

[Ulricehamn](https://www.ulricehamn.se/arkiv/nyheter/2025/2025-09-17-beredskapsmat-till-elever-pa-tva-skolor-i-ulricehamn) oppgir næringsberegnede krisemenyer, men artikkelen er en forhåndsomtale. Råberegninger og gjennomføringsresultater er ukjente.

[Livsmedelsverkets beredskapshåndbok](https://www.livsmedelsverket.se/globalassets/publikationsdatabas/handbocker-verktyg/beredskapshandbok-for-offentliga-maltider-2022/beredskapshandbok_for_offentliga_maltider_2022_webb.pdf), s.60–66, gir en anvendbar ressursmatrise og lageromløpsmetode. [Svinnhåndboken](https://www.livsmedelsverket.se/globalassets/publikationsdatabas/handbocker-verktyg/handbok-for-minska-matsvinn.pdf), s.11,20,27–30, gjør nevneren og måleavgrensningene tydelige: faktisk spisende må telles, og uspiselige fraksjoner inngår i den praktiske avfallsmetoden. Spiselig besparelse og ernæringsfunksjon trenger derfor egne målinger. Håndbøkenes tabell/formel er visuelt kontrollert på henholdsvis s.64 og s.29.

[funn og testdesign](findings.json) inneholder kildebytes-/tekst-/leseomfangshasher, eksakte lokatorer, fem observasjoner og koblingen node → flyt → avhengighet → forstyrrelse → tiltak → utfall. Alle fem whitepaperformål er koblet til hva denne runden faktisk kan og ikke kan underbygge.

Neste arbeid er MEAL-T001 hos ett navngitt kjøkken: sammenlign eksisterende norsk løsning, samme løsning med lageromløp/meny-/svinnmetode og et konkret nordisk metodetillegg under identiske avbrudd. Mål egnede måltider i tide, konsum, spiselig svinn, vann, energi, arbeid og kostnad gjennom hele valgt periode. Reserveutstyr alene er ikke sirkularitet. En svensk øvelse er ikke norsk nasjonal kapasitet eller nordisk tillegg.

Det åpne søket avsluttes med fire presise gap: øvelsesprotokoll/dato og næringsrådata, sammenlignbar driftsmåling, flerdøgnsforsyning og nordisk tillegg utover lokal optimering. Ingen av de fem leste kildene dokumenterer den etterspurte sirkulære eller nordiske effektstørrelsen; dette er ikke en påstand om at ingen slik studie finnes.

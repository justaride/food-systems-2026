2. **Lovstatus:** Lovdata viser at offentleglova endres ved lov 19. juni 2026 nr. 36, i kraft fra tidspunkt Kongen bestemmer. Sjekk status på sendetidspunktet og oppdater hjemmelshenvisningene hvis ny lov gjelder.
3. **Utsendingsgodkjenning:** Hver enkelt utsending logges i oppfølgingstabellen i vedkommende fil (dato, kanal, saksnummer, 5-dagersfrist jf. offentleglova § 32).
4. **Svarhåndtering:** Innvilget innsyn → mottakslogg → base. Avslag/«finnes ikke» → logg hjemmel, begrunnelse, saksnummer; klassifiser (source-gated / access-restricted / bekreftet fravær) etter review før det brukes som C-funn. Avslag alene er ikke fraværsbevis (gap-programmets metoderegel).

# Track Brief C: Adoption, governance og markedsmekanismer

## Problem

Spor A og B kan være teknisk og faglig riktige uten å bli tatt i bruk. Sirkulært fôr, sidestrømmer, matsvinnkvalitet og næringsstoffløkker blir først reelle tiltak når regulering, innkjøp, standarder, datakrav, markedsmakt og governance trekker i samme retning. Spor C skal derfor svare på hvordan A og B kan bli praktisk implementerbare, ikke bare interessante pilotideer (CL-C-001, CL-C-014).

## Hvorfor nå

Før scope-møtet 05.05.2026 må TG skille mellom hva som er et godt innsiktsspor og hva som er et gjennomførbart pilotspor. Adoption-mekanismene bør låses før pilotporteføljen låses, ellers risikerer prosjektet å velge piloter som ikke har lovlig substrat, kjøper, datagrunnlag, innkjøpskanal, rapporteringssystem eller operativ eier.

## Hva vi vet

1. Adoption av sirkulær mat må forstås som samspill mellom regulering, håndheving og markedsstruktur, ikke bare som teknologiadopsjon. Norske kilder om dagligvarestruktur, lov om god handelsskikk og konkurransetilsyn styrker dette som konkret adoption-gate (EV-C-001, EV-C-013, EV-C-015, CL-C-001).
2. EU Farm to Fork gir overordnet politisk retning for bærekraftige matsystemer, men dokumenterer ikke faktisk nordisk implementering eller operativ adoption (EV-C-003, CL-C-004).
3. UTP-regulering og norsk lov om god handelsskikk er relevant for markedsmakt i matverdikjeden, men rettslig ramme må skilles fra faktisk håndheving, rapporteringsvern og bruk. Per 2026-04-28 ligger ansvaret hos Dagligvaretilsynet, og det overføres til Konkurransetilsynet 2026-04-30 (EV-C-004, EV-C-005, EV-C-013, EV-C-014, CL-C-005, CL-C-006).
4. PPWR påvirker adoption gjennom emballasjedesign, gjenbruk, materialeffektivitet, matkontaktkrav og logistikk, særlig for dagligvare, HORECA og grossistledd. Norsk/EØS-ikrafttredelse må behandles som egen juridisk sjekk (EV-C-006, CL-C-010).
5. EUDR gjør soya og importerte fôrråvarer til et sporbarhets- og compliance-spørsmål. EU-kommisjonens oppdaterte kilde støtter soya-scope og EU-frister, men norsk/EØS-praktisering må avklares før sterke Norge-claims (EV-C-007, EV-C-017, CL-C-011).
6. Praktisk sirkulærøkonomi realiseres gjennom rutiner, sortering, infrastruktur og hverdagspraksis i butikk, husholdning og biogassanlegg (EV-C-010, CL-C-014).
7. Matsvinnstyring må forstås som governance-arkitektur med flere aktører og styringsformer. Frivillighet, lovgivning, marked, datarapportering og redistribusjon må vurderes sammen (EV-C-008, EV-B-014, CL-C-012).
8. Digitalisering og sporbarhet kan muliggjøre sirkulær matøkonomi, men manglende interoperabilitet, datastandarder, kost og kompetanse kan hindre adoption (EV-C-009).
9. DFØ/Anskaffelser.no gir norsk primærgrunnlag for offentlig innkjøp som demand-side mekanisme, men effekt og operativ kapasitet må valideres med innkjøpere, kjøkken og leverandører (EV-C-016, CL-C-002).
10. Recovery for importdata og prosess-sidestrømmer viser at KPI- og adoption-sporet må håndheve definisjon, år, geografi, enhet og kilde per tall, ellers sammenlignes actor-tall, svenske benchmark og norsk baseline feil (EV-A-017, EV-A-018, EV-B-018, EV-B-019, EV-B-020, CL-C-015).

## Hva vi tror

1. Offentlige matinnkjøp kan fungere som etterspørselsmotor for sirkulære og bærekraftige løsninger hvis mål, kompetanse, kontrakter, datakrav og kjøkkenpraksis er på plass (EV-C-002, EV-C-016, CL-C-002).
2. Operative KPI-er for innkjøp, matsvinn, sidestrømmer, næringsstoffløkker, sporbarhet og reststrømshåndtering kan bli et TG-verktøy, men bare hvis definisjoner, datatilgjengelighet og rapporteringssystemer bekreftes hos aktørene (EV-B-014, EV-B-016, EV-B-017, EV-C-011, EV-C-016, CL-C-015).
3. A og B bør ha felles valideringsgate for datakrav: substratdata, temperatur, holdbarhet, batchkvalitet, kontaminanter, opprinnelse, sluttbruk og rapporteringsansvar.
4. Markedsmakt og konsentrerte verdikjeder kan hindre adoption hvis nye leverandører ikke får tilgang til volum, kontrakter, logistikk eller rapporteringsvern.
5. TG bør ikke starte med å designe et bredt policyspor. Den bør først teste om konkrete adoption-mekanismer kan gjøre 1-2 piloter praktisk gjennomførbare.

## Adoption-mekanismer for A og B

| Mekanisme | Bruk for Spor A | Bruk for Spor B | Minimum før scope låses |
|---|---|---|---|
| Regulatorisk valideringsgate | Avklar lovlige fôrsubstrater, TSE/ABP, mattrygghet og EUDR-data for importerte råvarer. | Avklar lovlig sluttbruk for mat/ingrediens, fôr, biogass, biorest og næringsstoffprodukter, inkludert gjødselregelverk. | Skriftlig eller dokumentert faglig avklaring fra myndighet/fagekspert. |
| Innkjøp og demand-side | Fôr-/sjømataktør må bekrefte pris, volum, kvalitet og sporbarhetskrav. | Offentlig kjøkken, HORECA, dagligvare eller ingrediensaktør må bekrefte faktisk kjøps-/bruksinteresse. | Minst én demand-side aktør per pilotretning. |
| Standarder | Definer råvare-, prosess-, sikkerhets- og sporbarhetskrav for alternative fôringredienser. | Definer substrat-, temperatur-, holdbarhets-, renhets- og batchkrav. | Minimumsdataskjema per strøm eller pilot. |
| Datakrav | Koble EUDR, fôrdokumentasjon, leverandørkrav og eventuell LCA/KPI-logikk. | Koble matsvinn, sidestrøm, kvalitet, logistikk og sluttbruk til målbare KPI-er. | Bekreftet datatilgang og ansvarlig dataleverandør. |
| Markedsmakt | Test om nye fôrråvarer får tilgang til kjeden eller stoppes av kontrakter, prispress og risikooverføring. | Test om redistribusjon/høyverdi går tapt på grunn av rutiner, kontrakter eller insentiver. | Intervju med både leverandør og kjøper/driftsaktør. |
| Governance | Definer hvem som eier pilot, hvem som validerer risiko, hvem som kjøper og hvem som rapporterer. | Definer driftsansvar, dataansvar, kvalitetsansvar og regelverksreview. | Navngitt piloteier eller eksplisitt eierbehov. |

## Governance / funding

| Behov | Hva må skje |
|---|---|
| Beslutningsrekkefølge | TG bør først velge A+B som hovedretning, deretter bruke C til å teste om pilotene passerer adoption-gate. |
| Statusdisiplin | Alle adoption- og pilotclaims står som `Utført internt` til ekstern aktørrespons er dokumentert. |
| Funding | Finansieringsscreening bør kobles til governance-, forskning- og nordisk samarbeidsprogrammer før kapitaltunge teknologiløp prioriteres (EV-FIN-001). |
| KPI-er | KPI-er skal brukes som intern styring, ikke ekstern effektpåstand, før datatilgjengelighet, definisjoner og rapporteringsansvar er validert (EV-B-014, EV-B-016, EV-C-011, EV-C-016, CL-C-015). |
| Roadmap | Roadmap bør vise hvilke barrierer som må fjernes, hvem som eier dem, og hvilken validering som trengs før skala. |

## Decision ask

1. Beslutt at Spor C ikke går videre som eget hovedspor, men som tverrgående adoption- og governance-lag for Spor A og B.
2. Bruk C til å definere valideringsgater for hver pilot: lovlig substrat/sluttbruk, mattrygghet, demand-side, standarder, datatilgang, markedsmakt og piloteierskap.
3. Velg første adoption-kontakter: Mattilsynet, én offentlig innkjøps-/kjøkkenaktør, én fôr-/sjømataktør og én dagligvare/HORECA- eller matsvinnaktør.
4. Bestem hvilke KPI-er som kan brukes internt i roadmap, og hvilke som må vente til rapporteringssystemer er bekreftet.

## Anbefaling

Bruk Spor C som tverrgående adoption- og governance-lag for Spor A og B. C bør ikke bli et bredt policyspor i denne fasen. Den viktigste verdien er å gjøre pilotene beslutningsklare: hva er lov, hva kan kjøpes, hva kan måles, hvem eier driften, og hvilke markeds- eller governance-barrierer må håndteres før TG lover roadmap-effekt.

## Aktørspørsmål for første samtale

- Mattilsynet: Hvilke sirkulære substrater og sidestrømmer er realistiske under dagens regelverk, og hvilket minimum av dokumentasjon kreves før pilot?
- Offentlig innkjøper / kommunalt kjøkken: Hvilke sirkulære krav kan dere faktisk bruke i kontrakter, meny, drift og rapportering uten å skape urealistiske kost- eller kompetansekrav?
- Fôr-/sjømataktør: Hvilke krav til pris, volum, kvalitet, sporbarhet, EUDR-data og risiko må være på plass før alternative fôrråvarer vurderes?
- Dagligvare / HORECA: Hvor mister ferskvarer og sidestrømmer høyverdi i dag, og hvilke rutiner, tidsvinduer eller data kan flytte dem opp i kaskaden?
- Matvett / Too Good To Go: Hvilke operative data viser forskjell mellom forebygging, redistribusjon og restfraksjon, og hvor kan en pilot måle faktisk endring?
- Dagligvaretilsynet / Konkurransetilsynet: Hvilke markedsmakt-, handelsskikk- eller rapporteringsvernspørsmål bør TG forstå før den anbefaler nye leverandør- eller innkjøpsmodeller, særlig rundt myndighetsoverføringen 2026-04-30?
- Axfoundation / RecoLab: Hva er dokumentert læring fra eksisterende case, og hva er fortsatt uvalidert eller for lokalt til å kopiere?
- Landbruksdirektoratet/Miljødirektoratet: Hvordan skal norske aktører forholde seg til EUDR for soya og fôrråvarer, og hvilke deler er EU-krav, EØS-/norsk gjennomføring eller tredjelands-/eksportpraktikk?

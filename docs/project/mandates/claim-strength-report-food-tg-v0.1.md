# Claim Strength Report Food TG v0.1

Ingen claim i denne rapporten er `Validert eksternt`. Styrke betyr bare intern forskningsstyrke etter runde 4.

## 1. Skala

| Styrke | Betydning |
|---|---|
| Høy | Flere kildegrupper støtter claimet, og claimet kan brukes internt med tydelig avgrensning. |
| Medium | Godt grunnlag, men praktisk effekt, pilotbarhet eller datametode må valideres. |
| Lav | Hypotese eller kandidat; bør ikke brukes som konklusjon. |
| Benchmark | Sterkt som læring/case, ikke som pilot- eller effektbevis. |
| Hold tilbake | Må ikke brukes slik før primary-check eller actor-validation. |

## 9. Repair-kø

| Risiko | Reparasjon |
|---|---|
| Datatyper blandes | Lag tallregister per spor før decision memo v0.3. |
| Juridisk claim overdrives | Sjekk Lovdata/regjeringen/EØS/myndighet og skriv dato/status. |
| Pilot overclaims | Bruk gate: lov, kjøper, data, drift, governance. |
| Benchmark blir effektbevis | Merk alle benchmark eksplisitt og skriv hva de ikke støtter. |
| KPI blir pynt | Krev dataeier og frekvens før KPI brukes. |

## 10. Kort anbefaling

Bruk rapporten til å stramme språk i alle uttak: **valideringssprint før pilot**, **benchmark før effekt**, **datagate før KPI**, og **actor-response før statusløft**.

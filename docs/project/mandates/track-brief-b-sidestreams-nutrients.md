# Track Brief B: Sidestrømmer, matsvinnkvalitet og næringsstoffløkker

## Problem

Nordiske matsystemer taper verdi når spiselige varer, prosess-sidestrømmer, svartvann og biorest behandles som generisk avfall i stedet for differensierte ressurser. De største systemtapene ligger ikke bare i tonn matsvinn, men i kvalitetstap: blanding, sen sortering, svak proveniens, manglende kjølekjede og uklare sikkerhetskrav som sender materialer nedover i kaskaden til biogass, kompost eller forbrenning (CL-B-001, CL-B-008, CL-B-009).

## Hvorfor nå

Arbeidsplanen peker på Spor B som direkte koblet til mandatets næringsstoff- og ressursløkker, matsvinn, biobaserte reststrømmer og regenerativ praksis. For M13-M18 må TG velge intervensjoner som kan omsettes til aktørdialog, pilotmuligheter og roadmap i 2026-2029. Spor B bør brukes til å teste om TG kan flytte praksis fra "avfallshåndtering" til "kvalitetsstyrt ressursbruk" uten å overstyre mattrygghet eller regelverk.

## Hva vi vet

1. Matsvinn og sidestrømmer oppstår ulikt mellom land og verdikjedeledd; tiltak må skille mellom forebygging, redistribusjon og lavere verdsatt behandling (EV-B-001, CL-B-001).
2. Husholdninger er en stor og vanskelig matsvinnkilde i nordisk kontekst, og krever kombinerte virkemidler: atferd, teknologi, regulering og verdikjedesamarbeid (EV-B-002, CL-B-002).
3. Målegrunnlag og sektorfordeling finnes, men konkrete tall må primærkildesjekkes mot Matvett, SSB, Eurostat og nasjonale myndigheter før ekstern publisering (EV-B-003).
4. I svenske supermarkeder dominerer ferskvarer mye av svinnets økonomiske og miljømessige tap; forebygging og donasjon bør vurderes før biogass for restfraksjoner (EV-B-004).
5. Etter forebygging gir redistribusjon og bruk som dyrefôr ofte bedre miljøresultater enn biogass, kompostering, forbrenning og deponi, men rangeringen må vurderes per fraksjon og lokale systemgrenser (EV-B-005, CL-B-008).
6. Waste-to-nutrition-ruter er teknisk brede, men høyverdig bruk krever sikkerhetsstandarder, prosesstyring, regulatorisk avklaring og aksept, ikke bare biologisk egnethet (EV-B-006, CL-B-009).
7. Sjømat-sidestrømmer og bifangst er relevante nordiske høyverdimuligheter, men konkrete arter, volum og markedskanaler må låses med primærdata (EV-B-007).
8. Biogass, digestat og ny matproduksjon kan kobles i næringsstoffløkker som konseptbevis, men dette beviser ikke storskala økonomi eller regulatorisk gjennomførbarhet i dag (EV-B-008, CL-B-011).

## Hva vi tror

1. Havre-okara og lignende plantebaserte prosess-sidestrømmer kan være gode pilotinganger hvis volum, batchstabilitet, holdbarhet, nåværende destinasjon og pris bekreftes (CL-B-014, valideringsbehov: produsenter, ingrediensaktører, logistikkpartnere).
2. RecoLab/Helsingborg kan være nordisk referansecase for svartvann og næringsgjenvinning, men overføringsverdi avhenger av dokumentert tilkoblingsgrad, N/P/K-strømmer, sluttprodukter og regulatorisk status (CL-B-016, valideringsbehov: RecoLab/Helsingborg, NSVA, avløps- og gjødselmyndigheter).
3. Praktisk adopsjon av bedre sidestrømshåndtering avgjøres trolig av rutiner, sortering, infrastruktur og hverdagspraksis hos butikker, husholdninger og biogassanlegg, ikke av strategi alene (CL-C-014, valideringsbehov: Matvett, Too Good To Go, dagligvare, avfallsaktører).
4. Operative KPI-er for innkjøp, sidestrømmer, sporbarhet og reststrømshåndtering kan bli et viktig TG-verktøy, men bare hvis datatilgjengelighet og rapporteringssystemer bekreftes (CL-C-015, valideringsbehov: kommuner, HORECA, dagligvare og dataleverandører).

## Barrierer

| Type | Barriere | Evidens |
|---|---|---|

| Mattrygghet | Sidestrømmer til mat, fôr eller insektoppdrett må risikovurderes per substrat; kjemiske og mikrobiologiske farer kan følge strømmen videre. | EV-A-003, EV-A-004, CL-A-005, CL-A-006 |
| Regulering | Tidligere matvarer, swill, avløpsbaserte ressurser og kategoriavgrensninger krever juridisk og faglig avklaring før pilotdesign. | EV-A-004, EV-A-009, CL-A-006, CL-A-011 |
| Data | Baseline, sektorfordeling, N/P/K-strømmer, batchkvalitet og rapporterings-KPI-er er ikke modne nok til å brukes ukritisk i roadmap. | EV-B-003, EV-C-011, CL-C-015 |

## Pilotmuligheter

Disse er pilot-hypoteser basert på eksisterende `CL-B-*` og relevante `CL-C-*`, ikke formelle Pilotclaim-IDer. Claim-registeret har ikke eksplisitte Pilotclaim-rader for Spor B; formelle pilotclaims bør opprettes ved neste claim-register-oppdatering.

1. **Pilot B1: Renere prosess-sidestrøm til mat/ingrediens før biogass.** Scope: velg én strøm, for eksempel okara eller annen plantebasert batchstrøm, og test datakrav, kjøling, lagring, kvalitet og kommersiell avsetning. Mulig eier: produsent + ingrediensaktør, med NMBU som faglig støtte (EV-B-006, EV-B-011, CL-B-009, CL-B-014).
2. **Pilot B2: Matsvinnkvalitet i butikk/HORECA før restavfall.** Scope: bruke Matvett, Too Good To Go og en driftsaktør til å kartlegge hvor ferskvarer mister redistribusjonsverdi og hvilke data eller rutiner som flytter dem opp i kaskaden. Mulig eier: Matvett/Too Good To Go med dagligvare eller HORECA-partner (EV-B-004, EV-B-005, EV-C-010, CL-B-008, CL-C-014).
3. **Pilot B3: Svartvann-biorest-næring som nordisk referansecase.** Scope: sammenligne RecoLab/Helsingborg med ett eller flere norske avløpsanlegg for datakrav, N/P/K-flyt, sluttprodukt, regelverk og aksept. Mulig eier: RecoLab/Helsingborg + norsk avløpspartner (EV-B-008, EV-B-010, EV-B-013, CL-B-011, CL-B-016).

## Adoption / funding

| Mekanisme | Hva må skje |
|---|---|
| Kaskadestyring | TG bør bruke forebygging, redistribusjon, fôr/ingredienser, biogass/digestat og kompost som eksplisitt beslutningsrekkefølge, med fraksjonsspesifikke unntak. |
| Standardisering | Minimumsdata for substrat, temperatur, holdbarhet, kontaminanter, batchkvalitet og sluttbruk må defineres før pilot. |
| Logistikktilgang | Ren innsamling, kjølekjede, frekvens og transportkost må inn i pilotdesign fra start. |
| Offentlig etterspørsel | Kommunale kjøkken, offentlige innkjøp og avløpsanlegg kan gi testarena hvis datakrav og aksept er tydelige (EV-C-002, CL-C-002). |
| Finansiering | Spor B passer best med forsknings-, governance- og nordisk samarbeidsfinansiering før kapitaltunge teknologiløp prioriteres (EV-FIN-001). |
| Rapportering | KPI-er for sidestrømmer og næringsstoffløkker bør bare inngå i roadmap hvis aktørene kan måle dem konsistent (EV-C-011, CL-C-015). |

## Decision ask

1. Beslutt om Spor B skal være hovedspor-kandidat sammen med Spor A eller prioriteres som støttespor for adoption og pilotdesign.
2. Velg én første pilotretning: prosess-sidestrøm, butikk/HORECA-matsvinnkvalitet eller svartvann/biorest/næringsstoffløkke.
3. Avklar første aktørkontakt: RecoLab/Helsingborg for næringsløkker, Matvett/Too Good To Go for matsvinnkvalitet, eller Volare/NMBU for substratkrav.
4. Sett valideringsgate: dokumentert strøm, kvalitet, lovlig sluttbruk, logistikkost, datakrav og minst én aktør som kan eie drift.

## Anbefaling

Gå videre som hovedspor-kandidat med streng valideringsgate. Spor B er mandatnært, konkret og egnet til å koble matsvinn, sidestrømmer, svartvann, biorest og næringsstoffløkker i ett beslutningsspråk. Evidensen er sterk for kaskadeprinsipp, mattrygghetskrav og behovet for institusjonell koordinering, men svakere for konkrete nordiske pilotvolum, RecoLab-overførbarhet, okara-case og finansiering. TG bør derfor bruke Spor B til første aktørdialog og pilotshortlist, men ikke love skalaeffekt før data og regelverk er validert.

## Aktørspørsmål for første samtale

- RecoLab/Helsingborg: Hvilke dokumenterte N/P/K-strømmer, sluttprodukter og regulatoriske avklaringer finnes, og hva er den viktigste barrieren for å overføre modellen til norske forhold (CL-B-016)?
- Norske avløpsanlegg: Hvilke data om svartvann, slam, biorest og næringsinnhold måles i dag, og hva hindrer bruk som trygg næringsstoffressurs?
- Matvett: Hvor i norsk verdikjede skjer de mest beslutningsrelevante kvalitetstapene før redistribusjon eller høyverdig bruk, og hvilke data mangler for å prioritere tiltak (CL-B-001, CL-B-002)?
- Too Good To Go: Hvilke signaler, tidsvinduer eller produktdata gjør størst forskjell for å redde ferskvarer før de mister verdi i kaskaden (CL-C-014)?
- Volare/Finnprotein: Hvilke nordiske sidestrømmer oppfyller deres krav til renhet, næringsprofil, stabilitet og regelverk, og hva går i dag til biogass selv om det kunne hatt høyere verdi (CL-B-009, CL-B-014)?
- NMBU: Hvilke minimumstester kreves for å vurdere en sidestrøm som mat-, ingrediens- eller fôrressurs, og hvor går grensen mot biogass/digestat?
- Foodstudio: Hvilken fortelling eller arena kan gjøre kaskadebruk og næringsstoffløkker konkrete nok til at aktører forplikter seg til pilot?

# Worker 4C handoff - matsvinn, kaskade og redistribusjon

## 1. Kort konklusjon

Matsvinn er mest beslutningsrelevant for Food TG når kvalitetstapet kan knyttes til en konkret driftsbeslutning: tidligere nedprising, donasjon, alternativ salgskanal, bedre holdbarhetsstyring, batch-/porsjonsstyring, trygg fôr-/ingrediensrute eller restbehandling. Nasjonale totalvolum er nyttige som kontekst, men blir svake som pilotgrunnlag uten produktgruppe, tidspunkt, kvalitet, eier, mottaker og kontrafaktisk behandling.

Kaskaden bør formuleres som en beslutningsmatrise per fraksjon, ikke som en generell avfallshierarki-påstand. Trygg formulering:

> Hver fraksjon bør styres til høyeste lovlige og praktisk gjennomførbare bruk ved tidspunktet kvalitetstapet oppstår, med dokumentert matsikkerhet, dataeier, mottaker, alternativ behandling og rutineendring.

Matsvinnutvalget er sterkeste norske primær-/policykilde for 4C. Faggrunnlaget fra Albizzati og Eriksson støtter forebygging først, deretter redistribusjon/menneskemat og ofte fôr/ingredienser før biogass, kompost og forbrenning. Governance-kildene styrker at dette må kobles til rapportering, datakrav, innkjøp, markedsmakt, rutiner og drift, ikke bare teknologi.

Pilotmessig er `CL-B-022` sterk nok til å være første adoption-case eller fallback hvis teknisk B1-prosess-sidestrøm ikke raskt får råvareeier, hygieneavklaring og off-taker. Men `CL-B-022` skal fortsatt behandles som intern pilot-hypotese: den trenger baseline, dataeier, rutineendring og måling før effekt kan brukes.

## 2. Kaskadekart

| Kaskadenivå | Beslutningsspørsmål | Datakrav | Kildetype/anker | Kritisk svakhet |
|---|---|---|---|---|
| Forebygging | Kan overskudd eller svinn unngås før kvalitetstapet oppstår? | Bestilt/produsert/solgt/kastet, prognosefeil, årsakskode, holdbarhet, kampanje, gjestetall, økonomi. | Forskning: Albizzati; primær/policy: Matsvinnutvalget; adoption: Lehtokunnas. | Effekten kan flyttes til annet ledd eller skjules som lavere salg/tilgjengelighet. |
| Redistribusjon/menneskemat | Kan trygg mat nå mennesker tidsnok via ordinært salg, nedprising, donasjon eller alternativ kanal? | Produktgruppe, tid til utløp, temperatur, emballasje, aksept/avslag, mottaker, solgt/donert/kastet, alternativ destinasjon. | Primær/policy: Matsvinnutvalget; forskning: Eriksson; actor/case: Matsentralen/Too Good To Go/dagligvare-HORECA. | Kan dokumentere redistribusjon av overskudd uten å redusere overproduksjon; risiko for dobbelttelling og PR-metrikk. |
| Fôr/ingredienser | Hvis ikke menneskemat: kan fraksjonen lovlig og trygt bli fôr, ingrediens eller innsatsfaktor? | Råvarestatus, ABP/fôrstatus, renhet, allergen/kontaminanter, mikrobiologi, fukt/tørrstoff, temperatur, sporbarhet, mottakerspesifikasjon. | Primær: Mattilsynet/fôrregler; forskning: waste-to-nutrition og HACCP-lignende risikorammer; benchmark: okara/BSG. | Ikke alt matsvinn kan bli fôr. Kjøkken-/cateringavfall, animalske biprodukter og blandede fraksjoner kan stoppe ruten. |
| Biogass/næringsløkke | Når mat/fôr ikke er trygt eller praktisk, kan energi og næringsstoffer gjenvinnes? | Tonn til AD, metan/energi, biorest, N/P/K, fremmedstoffer, transport, faktisk bruk av digestat/biorest. | Forskning/benchmark: Stoknes, RecoLab/VA-case; primær: gjødsel- og avfallsregelverk. | Kan bli default for spiselig mat hvis sortering og tidsvinduer svikter. LCA avhenger av lokal energisubstitusjon og biorestbruk. |
| Kompost/forbrenning/rest | Er dette siste lovlige og praktiske rute for uegnet rest? | Restavfall kg, sorteringsgrad, kontaminering, behandlingsrute, kost. | Benchmark/kontekst: avfallshierarki og kommunal avfallspraksis. | Lav kaskadeverdi. Bør ikke brukes som "sirkulær løsning" uten tydelig restbegrunnelse. |

Praktisk 4C-regel: En strøm er TG-relevant hvis den har eier, tidspunkt, produktgruppe, kvalitet, lovlig alternativ mottaker og målbar rutine. Hvis ikke er den statistikk eller kildejakt.

| Situasjon | Anbefaling | Begrunnelse |

| Partner kan bare levere årlig kg, "måltider reddet", PR-tall eller omdømmeeffekt. | Ikke bruk som første pilot. | For svak kontrafaktisk metode og høy risiko for dobbelttelling/overproduksjon. |
| Offentlig kjøkken/kantine kan måle produksjon, servering, buffet/plate waste og rutineendring. | God HORECA-/innkjøpspilot. | Kontrollert drift og kobling til DFØ/anskaffelser. |
| Husholdningssvinn er hovedfokus uten butikk-, kommune-, emballasje- eller innkjøpskobling. | Ikke første TG-pilot. | Stort volum, men diffus eier og svak attribusjon. |

Minimumsgate for `CL-B-022`:

| Gate | Krav |
|---|---|
| Baseline | Minst 4 uker normal drift, helst 8 hvis sesong/kampanje påvirker ferskvarer. |
| Enhet | Kg og NOK per varegruppe; ikke bare måltider eller samlet sekkvekt. |
| Kvalitetstidspunkt | Tid til utløp, nedprisings-/donasjonstid, temperatur/kjølekjede og mottakers aksept/avslag. |
| Rutineendring | Én tydelig endring: tidligere nedprising, bedre donasjonshandoff, TGTG-cutoff, mindre buffetbatch, matvert, goodiebag eller årsakskoding. |
| Destinasjon | Ordinært solgt, nedpriset, alternativ kanal/TGTG, donert, lovlig fôr/ingrediens, biogass, kompost/forbrenning/rest. |
| Kontrafaktisk | Historikk, kontrollbutikk/-dag eller før/etter med kampanje-/sesongjustering. |
| Sikkerhet | Mattrygghetsansvar, temperaturkrav, merking, siste forbruksdag/best før og mottakeransvar avklart. |
| Dobbelttelling | Ikke summer nedprising, donasjon og TGTG som uavhengige effekter hvis samme vareflyt flyttes mellom kanaler. |

## 8. Røde flagg

| Rødt flagg | Konsekvens | Master-grep |
|---|---|---|
| Definisjonsbrudd mellom norsk matsvinn, EU matavfall, fôr, biprodukt og avfall. | Feil baseline, feil kaskade og feil KPI. | Alle tall må ha definisjon, år, geografi, enhet, kilde, metode og destinasjon. |
| Blandede måleår i Matsvinnutvalget og senere faktaark. | Falsk trend eller feil sektorfordeling. | Oppgi år per sektor/tall; ikke presenter som én ren 2021/2024-tabell uten fotnote. |
| Modellert virkemiddelpotensial blir behandlet som observert effekt. | Overclaim i decision memo. | Skriv "modellert potensial", ikke "forventet reduksjon"; ikke summer overlappende tiltak. |
| `NORSUS/Matvett 2024` og SSB-spor ikke fullt arkivert/sidetallsjekket lokalt i 2C. | Citation-risiko. | Sett i primary-check queue før ekstern bruk. |
| Too Good To Go / actor metrics brukes som uavhengig effektbevis. | PR- eller greenwashing-risiko. | Krev baseline, alternativ behandling, salgs-/donasjonsmiks og partnerdata. |
| Fôr/ingredienser omtales som mulig for alt matsvinn. | Juridisk/mattrygghetsfeil. | Bruk Mattilsynet/fagekspert per fraksjon; skill rene plantefraksjoner fra blandede/animalske/kjøkkenfraksjoner. |
| Biogass beskrives som "dårlig" i stedet for restfraksjonsrute. | Feil narrativ og dårlig aktørdialog. | Si at biogass er riktig for rest som ikke lenger kan gå til menneskemat eller lovlig fôr/ingrediens. |
| Husholdninger velges som direkte pilot fordi volumet er stort. | Svak eier, lang effektvei og dårlig attribusjon. | Bruk husholdninger som kontekst; pilot via butikk, kommune, emballasje, innkjøp eller servering. |
| Juridisk status for matsvinnlov/forskrifter brukes uten oppdatert primærsjekk. | Feil om gjeldende plikter. | Behandle lov/forskrift som primary-check før ekstern tekst. |
| KPI-er blir eksterne effektmål før dataeier er bekreftet. | Roadmap måler det aktørene ikke kan rapportere. | Følg 3F: KPI-er er intern gate til dataeier, frekvens og metode er bekreftet. |

## 9. Anbefaling til master

1. Bruk `CL-B-022` som rask adoption-/fallbackpilot i decision memo: "matsvinnkvalitet i butikk/HORECA kan bli første case hvis baseline, dataeier, rutineendring og mottaker/destinasjon kan dokumenteres." Ikke løft til effektclaim.
2. Hold kaskaden fraksjonsspesifikk. Standardformulering bør være "høyeste lovlige og praktisk gjennomførbare bruk", ikke "mest mulig kaskadebruk".
3. Sett Matsvinnutvalget som norsk primær-/policyanker for virkemidler, men lås NORSUS/Matvett 2024, SSB-definisjoner og lov-/forskriftsstatus i primary-check queue før ekstern bruk.
4. Bruk Albizzati, Eriksson, Szulecka og Lehtokunnas som forskningsanker: LCA/kaskade, butikkempiri, governance og praksis/adoption.
5. Opprett actor-validation-spørsmål til Matvett/NORSUS, SSB, Mattilsynet, Matsentralen, TGTG, én dagligvare/KBS-aktør og én HORECA/offentlig kjøkken-aktør. Spør om datafeltene i minimumsgaten, ikke bare generelle svinnvolum.
6. Ikke endre canonical claim-status nå. Alle claim-effekter fra 4C bør stå som `kan brukes internt`, `needs-primary-check`, `needs-actor-validation`, `benchmark` eller `hypotese`.
7. Hvis master må velge mellom B1 prosess-sidestrøm og B2 matsvinnkvalitet før actor-svar: velg B2 som adoption-case hvis en driftsaktør kan måle i 4-8 uker; velg B1 bare hvis råvareeier, hygiene/legal gate og off-taker er reelle.

## 10. Trygge uttaksformuleringer

- "Matsvinnkvalitet er beslutningsrelevant når den kan kobles til produktgruppe, tidspunkt, kvalitet, eier, mottaker og alternativ behandling."
- "Forebygging er normalt førstevalg; redistribusjon/menneskemat og lovlig fôr/ingredienser bør vurderes før biogass og restbehandling når fraksjonen fortsatt er trygg og praktisk håndterbar."
- "Butikk/HORECA er en sterk adoption-kandidat fordi rutiner, tidsvinduer og data kan endres raskere enn ny prosessteknologi."
- "KPI-er for matsvinn skal først være datakrav: definisjon, år, geografi, enhet, kilde, dataeier, frekvens og status."

## 11. Formuleringer som bør unngås

- "Matsvinn kan generelt bli fôr."
- "Too Good To Go/måltider reddet beviser redusert matsvinn."
- "Matsvinnutvalgets tiltak gir 340 000 tonn reduksjon."
- "Husholdninger bør være første direkte TG-pilot fordi volumet er størst."
- "Biogass er dårligere og bør alltid unngås."
- "NORSUS/SSB/Eurostat-tall kan sammenlignes direkte uten definisjonsbro."

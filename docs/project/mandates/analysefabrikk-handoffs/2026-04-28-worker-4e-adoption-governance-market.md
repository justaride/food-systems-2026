# Worker 4E handoff - adoption, markedsmakt, innkjøp og governance

## 1. Kort konklusjon

Adoption for Food TG bør behandles som en beslutningsrekkefølge, ikke som et generelt policytema:

1. **Lovlig handlingsrom**: substrat/sluttbruk, mattrygghet, fôr, gjødsel, EUDR/PPWR/UTP og norsk/EØS-status.
2. **Kjøper/off-taker**: en aktør som faktisk kan kjøpe, bruke, ta imot eller teste løsningen.
3. **Data og standard**: minimumsdata per batch, kontrakt eller rapporteringsperiode.
4. **Driftsevne**: kjøling, sortering, logistikk, QA, kjøkken-/butikkrutiner og rapportering.
5. **Governance/eierskap**: piloteier, risikoeier, dataeier, QA-ansvar og stoppregel.

Markedsmakt er tverrgående. Norsk dagligvare- og innkjøpsstruktur gjør at nye sirkulære løsninger kan stoppe i sortiment, kontrakt, pris, risikooverføring, datakrav, rapporteringsfrykt eller logistikk lenge før teknologien er problemet. Dette styrker C-sporet som gate for A/B, men ikke som eget hovedspor.

Per 2026-04-28 må håndhevingsstatus skrives med absolutte datoer: Dagligvaretilsynet er formell håndhevingsmyndighet frem til **30. april 2026**, da oppgavene etter lov om god handelsskikk flyttes til Konkurransetilsynet. Effekten av flyttingen er ikke dokumentert i praksis ennå.

## 4. Policy-to-Practice Map

| Policy-/governance-signal | Blir praksis gjennom | Hvor det kan stoppe | Adoption-gate |
|---|---|---|---|
| Lov om god handelsskikk / UTP | Kontrakter, skriftlighet, delistingregler, svinnansvar, klagekanal, kildevern og håndheving. | Lav tillit, frykt for gjengjeldelse, få formelle saker, kommersiell avhengighet. | Dokumentert trygg rapporteringsvei og kontraktsrisiko før pilot med dagligvare/HORECA. |
| Konkurransetilsynets dagligvarearbeid | Markedsanalyser, fusjonskontroll, konkurransehåndheving, markedsetterforskning og god-handelsskikk-ansvar fra 30. april 2026. | Verktøyene treffer ikke nødvendigvis pilotens konkrete leverandørbarriere eller kontrakt. | Bruk som strukturell risiko, ikke årsaksbevis uten aktørdata. |
| DFØ/offentlige anskaffelser | Kravspesifikasjon, 30 % klima-/miljøvekting, delkontrakter, klimakalkulator, matsvinn- og emballasjekrav. | Innkjøpskompetanse, rammeavtaler, prispress, kjøkkenkapasitet, leverandørmarked og måledata. | En innkjøper/kjøkken må bekrefte krav, data, kontraktsrom og drift. |
| EUDR | Sporbarhet, råvareopprinnelse, aktsomhetserklæring/DDS, kunde- og EU-markedskrav. | Norsk soya-scope er ikke foreslått innlemmet; varekoder, Traces, EORI og ansvar er uavklart. | Skill EU-plikt, norsk/EØS-status og kunde-/kontraktskrav. |
| PPWR | Emballasjedesign, matkontakt, PFAS, resirkulerbarhet, gjenbruk, transportemballasje og rapportering. | EØS-/norsk ikrafttredelse, kost, holdbarhet, mattrygghet og mulig matsvinnmålkonflikt. | Test per varegruppe: mindre/ny emballasje må ikke gi mer matsvinn eller svakere mattrygghet. |
| Matsvinn-/kaskadegovernance | Forebygging, nedprising, redistribusjon, sortering, kjølekjede, QA og restfraksjonsstyring. | Strategi uten driftsansvar, data uten eierskap, rutiner uten tid/kompetanse. | Operativ SOP, dataeier, driftsleder og avviksrutine. |
| KPI-roadmap | Definisjon, år, geografi, enhet, kilde, dataeier, frekvens og status per tall. | Datakost, ulike systemgrenser, manglende deling, kommersiell bruk av rapportering. | Ingen KPI-effekt uten dataeier, metode og rapporteringsfrekvens. |

## 10. Anbefaling til master

1. **Bruk C som tverrgående gate for A/B.** Decision memo bør si at TG går videre med A+B som hovedspor, men at C avgjør hvilke kandidater som faktisk er implementerbare.
2. **Løft adoption-gate som mastertabell.** Hver pilot må ha fem felt: lov, kjøper, data, drift og governance. Mangler ett felt, er piloten kandidat eller benchmark, ikke beslutningsklar.
3. **Prioriter B2 som rask adoption-test og B1 som teknisk kandidat.** Matsvinnkvalitet kan gi raskere praksislæring hvis baseline/driftspartner finnes; okara/BSG er mer konkret teknisk, men trenger produsentdata og off-taker.
4. **Hold A1/A2 som scopingpiloter inntil regulatorisk og kommersiell gate er låst.** Encelle-/gjærprotein og insektprotein er beslutningsrelevante, men ikke kommersielt eller juridisk ferdig validerte.
5. **Bruk EUDR presist.** Soya er EU-scope; norsk/EØS-status og praktisk betydning for norske fôr-/soyaaktører må holdes som uavklart/aktøravhengig.
6. **Ikke bruk KPI-er som effektfortelling.** Bruk CL-C-015 som intern kvalitets- og dataeiergate.
7. **Første actor-samtaler bør låse gates, ikke generelle meninger:** Landbruksdirektoratet/Miljødirektoratet, Mattilsynet/fagekspert, en fôr-/sjømataktør, en offentlig innkjøper/kommunalt kjøkken, en dagligvare/HORECA-/matsvinnaktør og en B1-råvareeier.

## 11. Master-uttak: kan sies nå / må vente

| Kan sies nå internt | Må vente |
|---|---|
| C er mest verdifullt som adoption-, governance- og datagate for A/B. | Endelig pilotvalg, skalaeffekt eller roadmap-effekt. |
| Norsk markedsstruktur, handelsskikk og håndheving er relevante adoption-risikoer. | At konkrete sirkulære leverandører allerede er blokkert av bestemte kjøpere. |

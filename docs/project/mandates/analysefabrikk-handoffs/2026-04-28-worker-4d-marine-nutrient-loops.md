# Worker 4D - marint restråstoff og næringsstoffløkker

## Kort konklusjon

Marint restråstoff er det sterkeste norske benchmarksporet i Spor B, men ikke den beste første lettvekts-piloten. SINTEF/FHF 2024 kan brukes som intern og siterbar baseline for volum, sektorfordeling og utnyttelsesgrad: ca. 1,094 mill. tonn tilgjengelig marint restråstoff i Norge i 2024, ca. 976 kt utnyttet, ca. 118 kt ikke utnyttet og 89 % samlet utnyttelse. Det må ikke brukes som bevis for høyverdi, matklarhet, fôrklarhet eller pilotklarhet per fraksjon.

Næringsstoffløkker bør behandles som benchmark- og datagate, ikke som første fysisk TG-pilot. RecoLab/Oceanhamnen lærer TG om kildeseparering, tre rør, N/P-logikk og governance. VEAS, HIAS og Den Magiske Fabrikken gir bedre norsk sammenligningsgrunnlag for sentral VA-rensing, ammoniumsulfat, struvitt, biogass og biogjødsel. Alle nutrient-loop-claims trenger produktstatus, N/P/K-massebalanse, lovlig sluttbruk og marked før de kan bære mer enn benchmark.

Anbefalt masterlinje: bruk marint restråstoff og nutrient loops som lærings- og benchmarkkart for CL-B-009, CL-B-016, CL-B-023 og CL-C-015. Hold CL-B-021 fortsatt rettet mot ren plantebasert prosess-sidestrøm, for eksempel okara eller bryggerimask, dersom første pilot må være rask, avgrensbar og aktørtestbar.

## Røde flagg

1. Ikke marker noe som eksternt validert; alle funn her er intern research, benchmark, hypotese, needs-primary-check eller needs-actor-validation.
2. Ikke gjør marint restråstoff til første plantebaserte B1-pilot. Det er sjømat-/fraksjonsspor og norsk benchmark.
3. Ikke bruk 89 % utnyttelse som høyverdi- eller matsirkularitetsclaim. Utnyttet inkluderer fôr, pet food, biogass/energi og teknisk bruk.
4. Ikke bland råstoffvekt, produktvekt, tørrstoff, våtvekt, N/P/K-masse og energitall i samme KPI.
5. Ikke omtale K2/dødfisk som vanlig mat- eller fôrråvare. Animaliebiproduktkategori og lovlig sluttbruk styrer.
6. Ikke oversett RecoLabs relative "3x P" og "7x N" til absolutte tonn uten massebalanse.
7. Ikke hevde K-gjenvinning i RecoLab/NPK-pellets uten å forklare KCl-tilsetning og massebalanse.
8. Ikke overføre svensk RecoLab-produktstatus til Norge uten Mattilsynet-/Landbruksdirektoratet-sjekk.
9. Ikke bruke VEAS N/P-rensegrad som synonym for næringsgjenvinning eller plantetilgjengelig gjødsel.
10. Ikke gjøre actor/case-nettsider til nasjonal statistikk. Bruk dem til rolle, prosess, produkter og spørsmål.
11. Ikke summere SSB slam, VEAS-produkter, HIAS struvitt, DMF biogjødsel og RecoLab-svartvann uten systemgrenser og dobbelttellingssjekk.
12. Ikke love pilotvolum, effekt, finansierbarhet eller roadmap-resultat før dataeier, lovlig sluttbruk og off-taker er bekreftet.

## Anbefaling til master

Integrer 4D som benchmark- og datagate, ikke som pilotvalg alene. Master kan trygt bruke SINTEF/FHF 2024 som norsk sjømatbenchmark med tallene 1,094 mill. tonn tilgjengelig restråstoff, 976 kt utnyttet, 118 kt ikke utnyttet og 89 % utnyttelse, samt sektorfordelingen hvitfisk 245/176/69 kt, pelagisk 285/285/0 kt, laksefisk havbruk 543/509/34 kt og skalldyr 21/5,6/15 kt.

For decision memo bør 4D bidra med tre poenger:

1. Marint restråstoff viser hva høyverdi krever: fraksjonering, ferskhet, kategori/status, kjølekjede, QA, sporbarhet, kunde og marked.
2. Nutrient loops viser hva KPI-er krever: N/P/K inn-ut, produktstatus, plantetilgjengelighet, kontaminanter, regelverk, mottakermarked og systemgrenser.
3. Første B-pilot bør fortsatt være enklere og mer avgrensbar enn sjømat/VA-infrastruktur, med mindre en konkret aktøreier raskt tilbyr data og driftstilgang.

Master bør derfor:

| Beslutning | Anbefaling |
|---|---|
| Første B-pilot | Hold ren prosess-sidestrøm eller matsvinnkvalitet som hovedkandidat hvis aktørdata kommer raskt. |
| Marint restråstoff | Bruk som norsk høyverdi-benchmark og mulig sekundær actor-learning track. |
| RecoLab/VEAS/HIAS/DMF | Bruk som sammenlignende benchmarkkart og datagate for CL-B-016/CL-B-023. |
| KPI | Gjør CL-C-015 til minimumskrav: definisjon, år, geografi, enhet, dataeier, kilde, systemgrense og frekvens. |
| Outreach | Prioriter SINTEF/FHF, én marin aktør, RecoLab/NSVA, VEAS, HIAS, DMF og Mattilsynet/Landbruksdirektoratet for primærsjekk og aktørvalidering. |

## Åpne spørsmål til neste runde

1. Kan SINTEF/FHF dele tabell eller datadictionary som krysser fraksjon, sektor, prosess og sluttbruk?
2. Hvor mye av marine produktgrupper er råstoff inn, produktvekt ut, tørrstoff eller våtvekt?
3. Hvilke hvitfiskfraksjoner utgjør 69 kt ikke utnyttet, og hvor mye er knyttet til havgående flåte?
4. Hva er faktisk sluttbruk for K2/dødfisk fordelt på biogass, forbrenning, gjødsel/jordforbedring og annen teknisk anvendelse?
5. Har RecoLab/NSVA oppdaterte 2026-tall for tilkobling, N/P/K-massebalanse, produkter og marked?
6. Kan VEAS, HIAS og DMF levere sammenlignbare N/P/K- og produktdata uten konfidensielle detaljer?
7. Hvilke gjødselprodukter eller avløpsbaserte råvarer kan lovlig brukes på hvilke arealer i Norge etter regelverket som trådte i kraft 1. februar 2025?
8. Hvilke KPI-er kan dataeierne faktisk rapportere kvartalsvis eller årlig uten ny tung infrastruktur?

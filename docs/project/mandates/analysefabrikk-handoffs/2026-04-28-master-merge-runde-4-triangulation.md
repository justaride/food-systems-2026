# Master merge runde 4 - triangulering

Runde 4 har gitt nok triangulert grunnlag til å stramme Food TG-scope, men ikke til å love pilot, ekstern effekt, finansiering eller aktørcommitment. Hovedbeslutningen er fortsatt **A+B som hovedspor, med C som adoption-, regelverks- og datagate**.

Ingen funn er ekstern aktørvalidering. Ingen canonical docs er oppdatert.

## 2. Mini-verifikasjon

Runde 4 bestod mini-verifikasjon som internt beslutningsgrunnlag. Kontrollpunktene som ble særskilt sjekket:

- Tall er i hovedsak utstyrt med år, geografi, enhet, definisjon og kilde.
- Juridiske funn er datert: EUDR EU-frister 30.12.2026 og 30.06.2027, norsk EUDR-høring 09.01.2026, Dagligvaretilsynet-overføring 30.04.2026, matsvinnloven 20.06.2025 med ikrafttredelse "Kongen bestemmer".

## 7. Hypoteser

- `CL-A-020`: Alternative fôrproteiner kan bli roadmap-spor hvis modenhet, kost, LCA, råvaretilgang, regelverk og kjøperkrav bekreftes.
- `CL-A-021`: Insektprotein kan bli A/B-case først etter juridisk substratgate og kjøper.
- `CL-B-021`: Okara/BSG kan bli første B-kandidat hvis råvareeier, hygiene og off-taker bekreftes raskt.
- `CL-B-022`: Matsvinnkvalitet kan bli første adoption-case hvis baseline, rutine og driftsaktør finnes.
- `CL-B-023`: Nutrient loops kan bli sekundærspor hvis produktstatus, N/P/K og lovlig sluttbruk er låst.
- `CL-C-002`: Offentlig innkjøp kan være demand-side hvis det kobles til konkrete kjøkken, kontrakter og data.

## 8. Archive/reject

| Formulering | Begrunnelse |
|---|---|
| "EUDR gjelder direkte i Norge for soya." | Norsk høringsgrunnlag sier soya ikke foreslås innlemmet i norsk virkeområde. |
| "`210610` viser SPC-import." | Koden er ikke soyaspesifikk og må metodeavklares. |
| "`23099040` er norsk laksefôrvolum." | Det er import av prepared fish feed, ikke total fôrbruk eller artsfordeling. |
| "Denofa/Skretting er norsk bransjesnitt." | Begge er actor-/benchmarkdata. |
| "Okara/BSG er pilotklart eller matgrade." | Råvareeier, hygiene, mat-/Novel Food-status og off-taker mangler. |
| "Måltider reddet er effektbevis." | Krever baseline, alternativ behandling og dobbelttellingskontroll. |
| "89 % marint restråstoff utnyttet betyr høyverdi." | Utnyttelse inkluderer fôr, pet food, biogass/energi og teknisk bruk. |
| "RecoLab kan kopieres som norsk pilot." | Infrastruktur, regulering, produktstatus og massebalanser er kontekstspesifikke. |
| "KPI-er dokumenterer roadmap-effekt." | KPI-er er datagate til dataeiere, frekvens og systemgrenser er validert. |

## 9. Beslutningskø

### Kan brukes nå

1. Scope: A+B som hovedspor, C som tverrgående gate.
2. EUDR: EU-scope og EU-frister, med Norge/EØS separat.
3. Fôr/import: SSB 08801, Fiskeridirektoratet totalfôr og actor-data som adskilte datalag.
4. B-kandidater: okara/BSG som benchmark og matsvinnkvalitet som fallback/adoption-case.
5. Benchmarks: marint restråstoff og nutrient loops som læring, ikke første pilot.
6. KPI: minimumsdatafelt, ikke effektmål.

### Må vente

1. Endelig norsk EUDR-status, varekoder, DDS/Traces og actor-praksis.
2. SPC, artsfordelt laksefôr og fôrråvareandel på tvers av aktører.
3. Okara/BSG food-grade, hygiene, volum, stabilisering og off-taker.
4. Matsvinnbaseline og driftsdata for butikk/HORECA.
5. Marine fraksjon-til-sluttbruk og nutrient-loop massebalanser.
6. Alle eksterne effekt-, pilot-, finansierings- og commitment-claims.

## 10. Stoppsignal

Ikke kommuniser ekstern roadmap-effekt, pilotvolum, finansierbarhet, aktørcommitment eller statusløft før:

1. EUDR-Norge er eksplisitt avklart eller merket uavklart med absolutte datoer.
2. Fôr/SPC/prepared-feed-metoden er ryddet med SSB/Tolletaten og fôraktører.
3. Første B-kandidat har minst én råvareeier, ett hygiene-/regelverkssvar og én off-taker eller driftsaktør.
4. KPI-er har dataeier, definisjon, enhet, geografi, år, frekvens og systemgrense.
5. Alle gjenværende claims er merket som hypotese, benchmark, `needs-primary-check` eller `needs-actor-validation`.

# Food TG Research Synthesis v0.1

## 1. Executive synthesis - 10 hovedfunn

1. Food TG bør snevres inn til **Spor A + Spor B**, med **Spor C som tverrgående adoption-, regelverks- og datagate**.
2. Første beslutning bør være en **valideringssprint**, ikke en pilotcommitment.
3. EUDR/sporbarhet er den viktigste datadriveren for A-sporet, men norsk/EØS-status og varekoder må formuleres separat fra EU-scope.
4. Alternative fôrproteiner er et sterkt strategisk scoping-spor, men ikke et kommersielt substitusjonsclaim.
5. Okara/BSG er mest konkret som teknisk B-kandidat, men mangler råvareeier, hygiene-/regelverksgate og off-taker i norsk/nordisk scope.
6. Matsvinnkvalitet i butikk/HORECA er den mest pilotbare adoption-kandidaten hvis partner kan dele baseline, kategori, tidsvindu og rutineendring.
7. Marint restråstoff er sterkt norsk benchmark, ikke første plantebaserte B-pilot.
8. RecoLab, VEAS, HIAS og Den Magiske Fabrikken er nyttige nutrient-loop benchmarks, men for tunge som første fysisk pilot.
9. Markedsmakt, handelsskikk, offentlig innkjøp og KPI-er må brukes som gates for A/B, ikke som brede egne policyspor.
10. Ingen claims er `Validert eksternt`; alle uttak må beholde statusdisiplin.

## 2. Hva er styrket siden runde 3

| Tema | Styrking |
|---|---|
| A-feed/import | SSB 08801, Fiskeridirektoratet/Sjømat Norge, Denofa og Skretting er tydeligere skilt som ulike datalag. |
| EUDR | EU-scope og EU-frister er sterkere, og norsk høringsstatus er tydeligere avgrenset. |
| Okara/BSG | Svenske benchmark er konkretisert med designkrav: fukt, temperatur, mikrobiologi, stabilisering, logistikk og off-taker. |
| Matsvinnkvalitet | `CL-B-022` er styrket som rask adoption-/fallback-kandidat med tydelig minimumsdesign. |
| Marint restråstoff | SINTEF/FHF 2024 gir sterk norsk baseline og kaskadelæring. |
| Nutrient loops | RecoLab, VEAS, HIAS og DMF er samlet som benchmarkkart, ikke første pilot. |
| Adoption | C-sporet er tydeligere operasjonalisert som gate: lov, kjøper, data, drift, governance. |
| Red-team | Overclaim-risiko og kill criteria er tydelig nok til å brukes før Jan Thomas/Cathrine-review. |

## 3. Hva er svekket eller må formuleres mer forsiktig

| Tema | Svakere formulering |
|---|---|
| EUDR-Norge | Ikke skriv at EUDR gjelder direkte i Norge for soya. Skriv EU-scope og norsk/EØS-status separat. |
| SPC/laksefôr | Ikke bruk `210610` eller `23099040` som SPC/laksefôr uten metodeavklaring. |
| Actor-data | Denofa og Skretting er actor-/benchmarkdata, ikke bransjesnitt. |
| Alternative fôrproteiner | Bruk som scoping og roadmap-hypotese, ikke substitusjonseffekt eller moden pilot. |
| Insektprotein | Bruk som kandidat etter substratgate, ikke som pilotklart sirkulært case. |
| Okara/BSG | Bruk som svenske benchmark og betingede kandidater, ikke pilotklare strømmer. |
| Matsvinn | Bruk kaskade per fraksjon og tidspunkt, ikke generell hierarkiretning. |
| Marint restråstoff | Bruk som høyverdi-benchmark; 89 % utnyttelse er ikke høyverdi-automatikk. |
| KPI | Bruk som datagate; ikke som ekstern effektfortelling. |

## 4. Triangulerte claims per spor

### Spor A - fôr, import og sporbarhet

| Claim | Foreløpig styrke | Trygg bruk | Må vente |
|---|---|---|---|
| `CL-A-020` alternative fôrproteiner | Medium | Strategisk scoping og import-/fôrdatagate. | Kommersiell modenhet, kost, LCA, råvaretilgang, regulatorisk vei og kjøperkrav. |
| `CL-A-021` insektprotein på godkjente sidestrømmer | Lav | Kandidat etter juridisk substratgate. | Grønn/gul/rød substratliste, insektaktør, fôrkjøper og risikodesign. |
| `CL-C-011` EUDR/sporbarhet | Høy for EU, Medium for Norge/praksis | EU-scope, EU-frister og datakrav som driver. | Endelig norsk/EØS-status, varekoder, DDS/Traces og actor-praksis. |

### Spor B - sidestrømmer, matsvinn og nutrient loops

| Claim | Foreløpig styrke | Trygg bruk | Må vente |
|---|---|---|---|
| `CL-B-009` designkrav for høyverdig bruk | Høy | Høyverdi krever kvalitet, hygiene, lovlig sluttbruk, sporbarhet og marked. | Per-substrat QA og regulatorisk avklaring. |
| `CL-B-014` okara/BSG | Medium som benchmark, Lav som pilot | Svenske benchmark og kandidatkort. | Norsk/nordisk volum, food-grade, holdbarhet, off-taker. |
| `CL-B-021` første prosess-sidestrømspilot | Lav/Medium | Betinget valideringsprioritet. | Råvareeier, Mattilsynet/fagekspert, stabilisering, kjøper. |
| `CL-B-022` matsvinnkvalitet | Medium/Høy som adoption-case | Rask pilotkandidat hvis baseline og driftspartner finnes. | Effektclaim, "måltider reddet", kontrafaktisk og datadeling. |
| `CL-B-023` nutrient loops | Medium benchmark, Lav pilot | RecoLab/VEAS/HIAS/DMF som læring. | Produktstatus, N/P/K, regelverk, aktøreier og marked. |

### Spor C - adoption, governance og data

| Claim | Foreløpig styrke | Trygg bruk | Må vente |
|---|---|---|---|
| `CL-C-001` adoption som regulering/marked/praksis | Medium/Høy | Hovedramme for C som gate. | Kausal påstand om konkrete leverandørbarrierer. |
| `CL-C-002` offentlig innkjøp | Medium | Demand-side testarena for konkret B-case. | Storskala effekt og anskaffbarhet uten innkjøper/kjøkken. |
| `CL-C-005` handelsskikk/UTP baseline | Høy | Rettslig ramme. | Faktisk håndhevingseffekt. |
| `CL-C-006` håndheving/rapportering | Høy som risiko | Behov for tillit, rapporteringsvern og praksis. | Effekt av flytting til Konkurransetilsynet etter 30.04.2026. |
| `CL-C-014` praksis og rutiner | Høy | Designprinsipp for adoption. | Kvantitativ effekt. |
| `CL-C-015` KPI/datastandard | Medium | Minimumsdata: definisjon, år, geografi, enhet, kilde, dataeier, frekvens, status. | Målverdier eller ekstern effekt. |

## 6. Pilot- og researchkø

| Rekkefølge | Arbeid | Formål |
|---:|---|---|
| 1 | EUDR/fôrdata primary-check | Fjerne risiko for feil EU/Norge-, varekode- og actor-vs-statistikk-claims. |
| 2 | Alternative fôrproteiner scoping | Avklare om A-sporet er roadmap, FoU-benchmark eller senere pilot. |
| 3 | Okara/BSG go/no-go | Sjekke råvareeier, hygiene, stabilisering, logistikk og off-taker. |
| 4 | Matsvinnkvalitet light pilot | Sikre rask adoption-case hvis teknisk B ikke modnes. |
| 5 | Adoption gate | Låse lov, kjøper, data, drift, governance og markedsmakt per kandidat. |
| 6 | Benchmark appendix | Bruke marint restråstoff og nutrient loops uten å gjøre dem til første pilot. |
| 7 | KPI-minimum | Standardisere tall før decision memo v0.3. |

## 8. Claims og temaer som må holdes tilbake

- EUDR som direkte norsk soya-plikt.
- SPC/laksefôrvolum uten metode.
- Denofa/Skretting som bransjesnitt.
- Pilotvolum for alternative fôrproteiner.
- Insektprotein på matavfall/slam/gjødsel uten regulatorisk avklaring.
- Okara/BSG som matgrade, Novel Food-avklart eller pilotklart.
- Matsvinn-effekt uten baseline og kontrafaktisk.
- Marint restråstoff som første plantebaserte B-pilot.
- RecoLab/VA/nutrient loops som kopierbar norsk pilot.
- KPI-er som effekt- eller målverdi.

## 9. Neste researchrunde eller outreach, hvis nødvendig

Runde 4 er ferdig som intern analysefase. Neste steg bør være en kort valideringssprint, ikke mer bred desk research. Decision memo v0.2 bør **skjerpes til v0.3**, fordi runde 4 bekrefter hovedscope A+B med C som gate, men endrer språk fra pilotprioritering til valideringsprioritering og legger sterkere stoppsignaler på EUDR-Norge, okara/BSG, matsvinn-effekt, marine fraksjoner og KPI-er.

## Anbefalt minimumsvedtak

Food TG kan gjennomføre en to-ukers intern casekort- og researchsprint basert på 09.06-samtalen. A+B/C beholdes som arbeidsramme; nye case behandles som caseanker og valideringshypoteser. Ingen ekstern outreach sendes og ingen claim løftes til eksternt validert før separat scope- eller minimumsvedtak foreligger.

## Hva vedtaket åpner

| Område | Kan starte nå | Krever senere beslutning |
|---|---|---|
| Case-shortlist | Velge 5-7 caseanker og lage casekort v0.1. | Endelig prioritering for ekstern presentasjon. |
| Analyse av eksisterende materiale | Koble casekort til A/B/C, CL-/EV-/SRC-IDer og åpne hull. | Ingen. Dette er repo-lokalt kontrollarbeid. |
| Målrettet research | Finne eller etterspørre interne dokumenter som MOU-er, prosjekttekster, deck og Notion-notater. | Ekstern henvendelse til aktører. |
| Claim hygiene | Oppdatere source shortlist, PCQ, claim-lock og actor validation pack. | Claim-løft til ekstern bruk. |
| Deck-outline | Lage intern 8-12 slides disposisjon uten ekstern faktastemme. | Produksjon av ekstern deck, sitater eller claims. |

## Beslutningsalternativer

| Alternativ | Innhold | Konsekvens |
|---|---|---|
| A - anbefalt | Godkjenn intern casekort-sprint med 7 caseanker og gated dokumentask. | Teamet får en styrt to-ukers arbeidsløype uten ekstern risiko. |
| B - smalere | Godkjenn bare 5 kjernecase: fôr/import, marint restråstoff, matsvinnkvalitet, okara/BSG og markedsmakt/adoption. | Kaffe/kakao, spillvarme/Valio og watchlist holdes utenfor første leveranse. |
| C - bredere | Godkjenn alle 7 caseanker pluss watchlist som aktiv researchkø. | Gir mer dekning, men øker risiko for at scope blir for bredt. |
| D - pause | Ikke start sprinten før formelt hovedscope er lukket. | Reduserer risiko, men 09.06-samtalen blir stående som uoperasjonalisert notat. |

## Dokumentask for intern avklaring

| Ask | Hvorfor | Stoppsignal |
|---|---|---|
| Brasil-MOU eller tilsvarende avtaletekst | Avgjør om kaffe/Brasil kan bli relasjonscase. | Ingen avtale, uklar partsliste eller ingen bruksrett. |
| Elfenbenskysten-MOU eller organisasjonsnavn | Avgjør om kakao-case er reelt eller bare samtalehypotese. | Manglende organisasjonsnavn, dato eller scope. |
| Kaffeprosjekt/Fuglen/Norsk Kaffeinformasjon | Avgjør om kaffe kan kobles til konkret aktør- eller prosjektløp. | Kun anekdote uten dokument eller kontaktperson. |
| Valio/Finland-kildepakke | Avgjør om Valio kan brukes som governance-/fôr-case. | Bare muntlig claim om importfritt fôr. |
| Bama/frukt-grønt/distribusjonsgrunnlag | Avgjør om dette er case, C-gate eller hold-tilbake. | Margin-/blokkeringsclaim uten kilde. |
| Spillvarme/drivhus/akvaponikk-kilde | Avgjør om lokal produksjon kan bli deckklart. | Ingen lokasjon, energi-/temperaturdata eller aktør. |

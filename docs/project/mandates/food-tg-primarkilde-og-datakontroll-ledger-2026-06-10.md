# Food TG Primarkilde- og Datakontroll Ledger 2026-06-10

Dette er arbeidsledgeren for 72t-sprinten etter at de aatte Deep Research-resultatene ble mottatt 2026-06-10. Ledgeren skiller mellom stabile primarkilder, kilder som bare kan brukes som PCQ-/actor-ask-grunnlag, benchmarkkilder og kandidater som skal parkeres.

## Bruksregel

Dette dokumentet kopierer ikke raw Deep Research-output inn i repoet, apner ikke ekstern outreach og gir ikke publiseringsklar faktastemme. En kilde kan bare paavirke `source-shortlist-food-tg.md` hvis den har eier, dato eller oppdatert lokator, konkret bruksverdi og tydelig begrensning. Relasjons-, partner-, margin-, pilot- og hoyverdiclaims holdes i PCQ/claim-lock til dokumenteier, dataeier eller aktorrespons finnes.

## Importbeslutningsnokkel

| Beslutning | Betydning |
|---|---|
| `shortlist-ready` | Kilden er stabil nok til source-shortlist som intern kilde med caveat. Ikke det samme som ekstern publiseringsklarhet. |
| `pcq-only` | Kilden styrer primary-check eller svekker et claim, men barer ikke claim alene. |
| `actor-ask` | Kilden peker til aktor, rolle, bruksrett eller data som maa valideres senere. |
| `data-needed` | Kilden bekrefter at data finnes eller trengs, men tall/metode maa trekkes ut separat. |
| `benchmark-only` | Kilden kan brukes som laering/designkrav, ikke som bevis for norsk/nordisk pilot. |
| `parkert` | Kilden eller sporet er for svakt for aktivt casearbeid naa. |

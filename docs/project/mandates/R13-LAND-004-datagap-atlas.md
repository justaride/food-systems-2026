# R13-LAND-004 - datagap-atlas

## Kort dom

R13 har nok materiale til å sortere datagap i desk-hentbare Type A, aktøravhengige Type B og reelle Type C-hull. Atlaset skal brukes som kontrollkø, ikke som bevis for manglende praksis eller som ekstern datagapfigur.

## Gap-atlas

| Område | Type A - desk kan hente | Type B - actor-gate | Type C - ikke åpent lukket | Ikke visualiser ennå |
|---|---|---|---|---|
| Import/beredskap | HS-tabeller, importår, produktkoder, offisiell metode. | Sluttbruk, lager, kontrakter og beredskapspraksis. | Samlet fôr-/matproteinrisiko med full sluttbruk. | Importnodekart uten sluttbruksgap og proxyetikett. |
| Sidestrømmer/svinn | Sektorrapporter, baseline-år, fraksjonsdefinisjoner. | Aktørvolum, faktisk behandling, double-count-kontroll. | Full nasjonal R-stige med fraksjonsflyt. | R-stige eller NPK-retur uten metode og enhet. |
| Protein/fôr | Landbruksdirektoratet, SSB, NIBIO, prosjektlocators. | Realisert produksjon, kundestrømmer, pilotstatus, mat/fôr-splitt. | Proteinselvforsyning i ett tall uten proteinfaktorer. | Kapasitetsgraf som blander plan og produksjon. |
| Aktører/nettverk | Brreg, kart-/plattformlocators, ordningseiere. | Aktiv-status, medlemstall, gårdsbekreftelse, eierskap/founders. | Komplett deduplisert register over alle alternative produsenter. | Aktørkart uten verifisert aktiv status. |
| Innovasjon | Forskningsrådet, EU, virkemiddelprogram, prosjektportaler. | Søkerrolle, konsortium, finansieringsutfall, implementert effekt. | Survival/failure-rate som teknologidom. | Funding-/økosystemkart uten rolle og status. |
| Økologi/agroøkologi | SSB/Debio, Landbruksdirektoratet, NIBIO, Mattilsynet, Naturindeks. | Auditdata, gårdspraksis, effektmåling, merkeordningsavvik. | Regenerativ/agroøkologisk nettoeffekt per gård i offentlig register. | Miljøscore uten effekt- og auditdata. |
| Land/makt | KT, Menon/NFD, Brreg, årsrapporter, markedsregulatorer. | Grossistvilkår, franchiseavtaler, kontraktskontroll, aktørbekreftelser. | Én samlet åpen maktkonsentrasjonsmetode på tvers av matsystemet. | Makt-/eiergraf uten metode, dato og tomme celler. |

## Kontrollbruk

| Kontrollspørsmål | Bruk |
|---|---|
| Finnes en primær/offisiell locator? | Send til PCQ hvis tall, metode og scope er tydelig. |
| Er kilden aktør, prosjekt eller nettverk? | Hold i source-shortlist med kildeklasse og tomme celler. |
| Krever feltet aktiv status, avtale, eierprosent eller volum? | Send til actor-gate. |
| Er raden bare syntese eller modell? | Hold som internal/forståelse og ikke importer som kilde. |

## Tomme celler som går igjen

- Aktiv-status per produsent, gård, ring, andelslandbruk og markedshage.
- Realisert volum per år, ikke bare kapasitet, plan, pilot eller mål.
- Sluttbruk og double-count-kontroll for import, fôr og sidestrømmer.
- Kontrakts-, grossist- og franchisevilkår.
- Aksjonær-/konserndata med dato og prosent.
- Auditdata, praksisdata og effektmåling for merkeordninger/agroøkologi.
- Figurgrunnlag med enhet, metode, nevner, kildeklasse og svakeste punkt.

## Ikke si

- Ikke si at et datagap beviser at praksisen ikke finnes.
- Ikke si at intern gapklassifisering er en kilde.
- Ikke gjør Type C til dramatisk narrativ uten metode.
- Ikke lag datagap-atlas som ekstern figur før tomme celler, gate og kildeklasse vises.

## Anbefalt gate

`internal`. Atlaset skal bare styre neste arbeid: PCQ, source-shortlist, actor-gate eller parkering.

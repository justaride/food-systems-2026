# Decision Memo Food TG Scope v0.1

## Beslutning som forberedes

Food Transition Group må velge et smalt nok scope til å rekruttere aktører, teste 1-2 piloter og bygge et 1-3 års roadmap, uten å overselge uvaliderte claims. Dette memoet anbefaler hvilke spor som går videre, hvilke piloter som bør testes først, hvem som bør kontaktes først, og hva som må valideres før scope låses.

Status: dette er et internt beslutningsutkast. Ingen pilot, aktør eller claim er `Validert eksternt` per 2026-04-27.

## Kort anbefaling

1. **Hovedspor:** Gå videre med Spor A og Spor B som hovedspor.
2. **Tverrgående lag:** Bruk Spor C som adoption-, governance- og valideringslag for A og B, ikke som eget hovedspor.
3. **Første pilotvalidering:** Test `CL-A-021` insektprotein på godkjente sidestrømmer først, fordi den kobler A+B+C i ett konkret case.
4. **Andre pilotvalidering:** Test `CL-B-021` ren prosess-sidestrøm til mat/ingrediens før biogass hvis produsentdata kan skaffes raskt.
5. **Fallback / lavterskelpilot:** Hold `CL-B-022` matsvinnkvalitet i butikk/HORECA som rask adoption-pilot hvis teknisk substratpilot tar for lang tid å validere.

## Sporvalg

| Spor | Anbefaling | Begrunnelse | Forbehold |
|---|---|---|---|
| A: Sirkulært fôr og importavhengighet | Hovedspor | Mandatnært, kobler sjømat/husdyr, importavhengighet, råvaresporbarhet og nordisk beredskap. Har sterke tekniske og regulatoriske spørsmål som kan mobilisere relevante aktører. | Ikke lov effekt, volum eller kommersiell skala før modenhet, kost, regulatorisk vei og demand-side er validert. |
| B: Sidestrømmer, matsvinnkvalitet og næringsstoffløkker | Hovedspor | Mandatnært, konkret og egnet til piloter. Gir TG et praktisk språk for kaskadebruk, kvalitet, mattrygghet, logistikk og næringsstoffløkker. | Ikke tallfest pilotvolum, N/P/K-flyt eller økonomi før strømdata og lovlig sluttbruk er bekreftet. |
| C: Adoption, governance og markedsmekanismer | Tverrgående lag | Svarer på hvordan A og B faktisk kan tas i bruk gjennom regulering, innkjøp, standarder, datakrav, markedsmakt og governance. | Bør ikke bli bredt policyspor nå. Brukes som valideringsgate for A/B. |

## Pilotprioritering

| Prioritet | Pilotclaim | Pilot | Hvorfor først | Første validering |
|---|---|---|---|---|
| 1 | CL-A-021 | Insektprotein basert på godkjente nordiske sidestrømmer | Tester A+B+C samtidig: importsubstitusjon, sidestrømskvalitet, mattrygghet, TSE/ABP, standarder, data og kjøperkrav. | Lovlig substrat, mattrygghetskrav, aktørkapasitet, fôr-/sjømatkjøper og datakrav. |
| 2 | CL-B-021 | Ren prosess-sidestrøm til mat/ingrediens før biogass | Konkret kaskadepilot med tydelig beslutningslogikk: kan en ren strøm holdes høyere i verdikjeden før den faller til biogass eller lavere verdi? | Produsentdata, volum, batchkvalitet, holdbarhet, logistikk, nåværende destinasjon, lovlig sluttbruk og ingrediens-/matkunde. |
| Fallback | CL-B-022 | Matsvinnkvalitet i butikk/HORECA før restavfall | Raskere adoption-pilot hvis A/B-substratsporet trenger mer regelverksavklaring. Kan mobilisere Matvett, Too Good To Go og driftsaktører. | Baseline, målepunkt, rutineendring, redistribusjonslogistikk, KPI-er og driftsaktør. |
| Sekundær | CL-A-020 | Encelleprotein/gjærprotein som importsubstitusjon i laksefôr | Faglig sterkt, men mer FoU-/teknologimodenthetsavhengig. Passer som scopingpilot eller parallell ekspertvalidering. | Foods of Norway/NMBU, fôrprodusent, Mattilsynet, LCA/kost og sjømataktør. |
| Sekundær | CL-A-022 | Axfoundation/Framtidens foder benchmark | Nyttig for governance og finansieringslæring, men bør ikke være første go/no-go for TG-scope. | Prosjektstatus, resultater, finansieringsmodell og overføringsverdi. |
| Sekundær | CL-B-023 | RecoLab/Helsingborg + norsk avløpspartner | Relevant for næringsstoffløkker, men for tungt som første pilot uten bekreftede N/P/K-data og regulatorisk status. | N/P/K-flyt, sluttprodukt, tilkoblingsgrad, regelverk, aksept og norsk overføringsverdi. |

## Første kontaktrekkefølge

| Rekkefølge | Hvem | Hvorfor | Primært spørsmål |
|---|---|---|---|
| 1 | Mattilsynet / EU-EØS regelverkskompetanse | Avgjør om første A/B-pilot i det hele tatt kan designes lovlig og trygt. | Hvilke substrater/sluttbruk er realistiske, og hvilken dokumentasjon kreves? |
| 2 | Foods of Norway/NMBU | Gir faglig gate for fôr, encelleprotein, mattrygghet, LCA, modenhet og forsøksdesign. | Hva er sterkt nok til roadmap, og hva må ikke brukes som ekstern påstand ennå? |
| 3 | Volare/Finnprotein eller tilsvarende insekt-/fôraktør | Tester om `CL-A-021` har reell industriell inngang. | Hvilke sidestrømmer kan dere bruke i dag, og hva stopper kapasitet, kundeinteresse og regulatorisk skala? |
| 4 | Fôr-/sjømataktør | Sikrer demand-side før pilot blir teknologidrevet. | Hvilke krav til pris, volum, kvalitet, sporbarhet og risiko må være oppfylt? |
| 5 | Produsent/ingrediensaktør for ren prosess-sidestrøm | Tester `CL-B-021` med faktiske strømdata. | Finnes det en ren, stabil strøm med dokumentert volum, kvalitet, holdbarhet og mulig avsetning? |
| 6 | Matvett / Too Good To Go / dagligvare eller HORECA | Holder lavterskel adoption-pilot klar. | Hvor mister varer redistribusjonsverdi, og hvilke data/rutiner kan flytte dem opp i kaskaden? |
| 7 | Axfoundation og RecoLab/Helsingborg | Benchmark etter at hovedgate er testet. | Hva er dokumentert læring, og hva er for lokalt eller uvalidert til å kopiere? |

## Hva må valideres før scope låses

| Valideringspunkt | Minimumskrav | Relevante claims |
|---|---|---|
| Lovlig substrat og sluttbruk | Dokumentert regulatorisk vurdering for valgt strøm og sluttprodukt. | CL-A-005, CL-A-011, CL-A-021, CL-B-009, CL-B-021 |
| Mattrygghet og risikomodell | Klart minimum for testing, kontaminanter, hygienekrav, HACCP-lignende vurdering og ansvar. | CL-A-005, CL-A-006, CL-B-009 |
| Strømdata | Volum, batchstabilitet, temperatur, holdbarhet, renhet, nåværende destinasjon og pris/logistikk. | CL-B-014, CL-B-021 |
| Demand-side | Minst én potensiell kjøper eller bruker som kan beskrive krav og terskler. | CL-A-020, CL-A-021, CL-B-021, CL-B-022, CL-C-002 |
| Datakrav og KPI-er | Bekreftet datatilgang, rapporteringsansvar og hvilke KPI-er som kan brukes internt. | CL-C-011, CL-C-015 |
| Markedsmakt og kontrakter | Avklart om kontrakter, innkjøpsmakt eller rapporteringsfrykt hindrer leverandører eller nye aktører. | CL-C-001, CL-C-005, CL-C-006 |
| Governance | Navngitt piloteier eller tydelig eierbehov, regulatorisk reviewer, dataleverandør og demand-side aktør. | CL-C-014 |
| Finansieringsmatch | Foreløpig match mot forsknings-, governance- eller nordisk samarbeidsfinansiering. | EV-FIN-001 |

## Beslutningsforslag til scope-møtet 05.05.2026

1. Food TG scope låses foreløpig til **A+B med C som adoption-lag**.
2. Første sprint går til aktørvalidering av `CL-A-021` og `CL-B-021`.
3. `CL-B-022` holdes som lavterskel adoption-pilot hvis teknisk/regulatorisk validering av `CL-A-021` eller `CL-B-021` tar mer enn én sprint.
4. `CL-A-020`, `CL-A-022` og `CL-B-023` holdes som sekundære spor: relevante, men ikke første beslutningsgate.
5. Ingen ekstern roadmap-effekt, pilotvolum, finansierbarhet eller aktørcommitment kommuniseres før valideringspunktene over er dokumentert.

## Risikoer hvis anbefalingen ikke følges

| Risiko | Konsekvens |
|---|---|
| Velge teknologispor uten adoption-gate | TG kan ende med FoU-case uten kjøper, regelverksvei eller driftseier. |
| Velge for bredt scope | Aktørrekruttering og roadmap blir uklare, og M13-M18 blir vanskeligere å dokumentere. |
| Overselge interne claims | Ekstern troverdighet svekkes hvis uvaliderte aktør-, volum- eller regelverksclaims presenteres som fakta. |
| Starte med tung infrastrukturpilot | RecoLab/svartvann-sporet kan binde kapasitet før enklere A/B-piloter er testet. |
| Bruke KPI-er for tidlig | Roadmap kan styre etter indikatorer aktørene ikke kan måle konsistent. |

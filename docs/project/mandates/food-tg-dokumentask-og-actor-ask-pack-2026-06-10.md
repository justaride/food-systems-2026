# Food TG Dokumentask og Actor Ask Pack 2026-06-10

Dette dokumentet er arbeidslaget mellom Deep Research-output, interne dokumenteiere og senere aktørvalidering. Det skal gjøre spørsmålene så presise at et svar kan brukes direkte til å oppdatere mottakslogg, PCQ, source-shortlist, actor validation pack eller claim-lock.

For rekkefølge og go/no-go-prioritet brukes `food-tg-0906-sprintboard-go-no-go-2026-06-10.md`. For hvilke dokument- og aktørspor som faktisk kom ut av de mottatte Deep Research-resultatene, se `food-tg-deep-research-results-intake-2026-06-10.md`.

## Bruksregel

Dette er ikke outreach. Ingen e-post eller ekstern kontakt skal sendes fra dette dokumentet før scope- eller minimumsvedtak åpner det. Første bruk er intern dokumentinnhenting hos Gabriel/Cathrine/JT/Einar/NCH/WCEF/Natural State eller annen dokumenteier.

Svar skal ikke behandles som eksternt validert før de har dato, rolle, dokument/kilde, bruksrett og eventuell sitatsjekk. Muntlige signaler kan logges som intern hypotese, men ikke som faktastemme.

## Tre valideringsnivåer

| Nivå | Formål | Hvem | Kan låse opp | Kan ikke låse opp alene |
|---|---|---|---|---|
| L0 intern dokumentask | Finne dokumenter, dokumenteier, bruksrett og scope. | Gabriel, Cathrine, JT, Einar, NCH/WCEF/Natural State. | Om case overlever som intern arbeidshypotese eller skal parkeres. | Ekstern faktastemme eller aktørclaim. |
| L1 primærkildesjekk | Bekrefte offentlige/aktør-eide dokumenter, data og metode. | Myndighet, institusjon, prosjektarkiv, selskapsside, rapportutgiver. | Source-shortlist eller PCQ-oppdatering. | Bruksrett til sitat eller partnerrolle uten dokumenteier. |
| L2 aktørvalidering | Bekrefte rolle, tall, definisjon, bruksrett og sitatsjekk. | Navngitt aktør, dataeier, fagperson eller organisasjon. | Claim kan vurderes for intern/ekstern bruk via claim-lock. | Publisering uten claim-lock og locator-sjekk. |

## Minimumskrav til alle svar

| Felt | Krav |
|---|---|
| Dokument | Fil, URL, tittel, dato, eier/utgiver eller klar melding om at dokument ikke finnes. |
| Rolle | Hvem svarer, rolle/funksjon og om personen er dokumenteier, formidler eller fagkilde. |
| Bruksrett | Intern bruk, ekstern omtale, sitatbruk, kun bakgrunn eller ikke bruk. |
| Status | Bekrefter, delvis bekrefter, avkrefter, ukjent eller kan ikke deles. |
| Locator | Side, avsnitt, slide, tabell, datakilde, eller "ikke tilgjengelig". |
| Neste gate | Source-shortlist, PCQ, actor validation pack, claim-lock, casekort eller parkering. |

Case/ask: [DASK-0906-XXX - kort case]

## Importbeslutning etter respons

| Responsutfall | Beslutning |
|---|---|
| Dokument finnes og kan brukes internt | Oppdater mottaksfil/casekort og vurder source-shortlist hvis kilden er stabil. |
| Dokument finnes, men kan ikke brukes eksternt | Bruk som intern styring; ikke løft claim. |
| Dokument finnes, men scope er annet enn antatt | Oppdater claim-lock med svekket eller avgrenset claim. |
| Dokument finnes ikke | Behold `needs-source`, sett `watchlist` eller parker caset. |
| Aktør kan bekrefte rolle/data med bruksrett | Flytt til actor validation pack og vurder claim-lock-delta. |
| Aktør kan bare gi bakgrunn | Logg som intern kontekst, ikke source-shortlist eller claim-bevis. |

## Hvorfor dette må avklares nå

Food TG har en sterk intern kunnskapsbase og en grønn kilde-/citation-baseline. Det som fortsatt mangler er formell intern scope-bekreftelse og ekstern aktørvalidering.

Uten scope-beslutning kan prosjektet fortsatt forberede outreach og dokumentstruktur, men bør ikke:

- sende bred ekstern valideringsrunde
- omtale scope som låst
- skrive roadmap som om pilotrekkefølgen er besluttet
- oppdatere claim-status til eksternt validert

## Anbefalt beslutning

```text
Food TG går videre med Spor A+B som hovedscope, med Spor C som tverrgående adoption-, regelverks- og datagate. Gruppen kjører en 10 arbeidsdagers valideringssprint før pilotcommitment. Ingen claims løftes til ekstern validert status før primærsjekk eller aktørvalidering er dokumentert.
```

## Beslutningsalternativer

| Alternativ | Hva besluttes | Konsekvens |
|---|---|---|
| A | A+B som hovedscope, C som gate | Anbefalt. Gir smal nok valideringssprint og dekker møtenes prioriteringer. |
| B | Bare A som hovedscope | Mer spisset, men svekker sidestrøm/matsvinnkvalitet som møtene har løftet. |
| C | Bare B som hovedscope | Praktisk og sirkulært tydelig, men svekker import-/fôr- og beredskapskoblingen. |
| D | Utsett scope | Trygt formelt, men blokkerer ekstern validering og roadmap. |

## Anbefalt minimumsvedtak

Hvis JTO/Cathrine/Einar ikke vil låse full scope ennå, bør de minst bekrefte:

```text
Food TG kan kjøre en begrenset valideringssprint på A+B/C-hypotesen uten at dette regnes som endelig scope- eller pilotcommitment.
```

Dette gir lov til å kontakte P1-aktører som faglig validering, samtidig som prosjektet beholder riktig statusdisiplin.

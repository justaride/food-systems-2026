# Spor C — Sandbox (utforskning/strategi)

> **Dette er ikke kunnskapsgrunnlaget.** Alt her er **spor C: utforskning** — scenarier, hypoteser, «hva hvis», strategi- og produktidéer, provokasjoner. Det er bevisst spekulativt, og skal **aldri** siteres som fakta eller mate deck/hvitbok/claim-lock direkte.

## Hvorfor sporet finnes

Den strenge prosessen (primærkilde → claim-lock → gate) er riktig for det *siterbare* grunnlaget, men for trang for tenkning som ennå ikke skal være fakta. Spor C er rommet der vi får jobbe fritt — uten kildekrav — så lenge det er **merket** som utforskning. Det er ikke slurv; det er et bevisst tankerom.

## De fire sporene (kort)

| Spor | Hva | Beviskrav | Siterbar utad? |
|---|---|---|---|
| **A** Kunnskapsgrunnlag | siterbare fakta | primærkilde + claim-lock + gate | ja (m/caveats) |
| **B** Analyse/syntese | systemmodell, objektivfunksjon, kryss-koblinger | koherens + evidens-pekere til A | som analyse, aldri som fakta |
| **C** Utforskning *(her)* | scenarier, hypoteser, strategi, idéer | eksplisitt spekulativ; ingen kildekrav | nei — internt |
| **D** Produkt/plattform | app-bygging | lint/build/test + control-layer | produktet selv |

## Reglene (membranen)

1. **Merk alt.** Hver fil her starter med en spor-C-banner. Ingen tvil om hva det er.
2. **Fakta som substrat er fritt.** Du kan referere spor A/B-funn som utgangspunkt og bygge fritt på toppen (nedover er fritt).
3. **Ingen lekkasje oppover.** Ingenting herfra går inn i grunnlaget, decket eller claim-lock uten **forfremmelse**.
4. **Forfremmelsesvei:**
   - **C → B:** en hypotese blir analyse når den forankres i evidens-pekere til spor A.
   - **B → A:** en syntese blir siterbar fakta når det siterte re-hentes som primærkilde og verifiseres.
   - Forfremmelse er den *eneste* veien opp — aldri implisitt.
5. **Spekulasjon skal være ærlig spekulasjon.** Marker antakelser, ekstrapolasjoner og «dette vet vi ikke» tydelig — også her. Friheten er fra kildekrav, ikke fra redelighet.

## Hva sporet er godt for

Scenarier og stresstester, strategiske opsjoner, produkt-/plattformidéer, motargumenter og «red team», og — nyttig bivirkning — å **generere research-agendaen**: et godt scenario avdekker presis hvilke spor-A-tall vi mangler for å ta det videre. Slik mater det åpne sporet det disiplinerte.

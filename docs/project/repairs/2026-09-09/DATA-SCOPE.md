# FS-19/20: dataomfang og ferskhet

Denne rettingen skiller kildekontroll fra byggetid og setter bruksgrensen ved tallene på `/sirkularitet`, `/havbruk`, `/media` og `/politikk`.

| Side | Faktisk utvalg | Ferskhet som kan vises | Gjenstående databehov |
|---|---|---|---|
| Sirkularitet | Kuraterte looper, gap og aktørcaser; landratene er økonomiomfattende materialstrømmodeller, ikke mål for matsektoren | `generated` er bare byggetid; samlet kildekontroll mangler | Kildeperiode og kontrolltid per case; undersøk tomme celler og benchmarkgrunnlag |
| Havbruk | Rader i lokal database fra Fiskeridirektoratets API | Uttaks-/kontrolltid er ikke lagret | Datert registertotal, dekningsandel og avstemte konsernkoblinger |
| Media | Kodede oppføringer og redaksjonelle landprofiler; landkortet med høyest signalverdi gjelder bare profilskåren, ikke samlet medieomtale | Publiseringsperiode kan avledes fra oppføringene; kontrolltid mangler | Søkestrenger, kanalunivers, uttaksdato og bredere landdekning |
| Politikk | Tematisk sammenligning av fem land og EU | Kilder sist kontrollert 2026-04-29; genereringsdato er ikke ny kontroll | Navngitt dataansvarlig, neste kontroll og ny primærkildesjekk |

Ingen database-, godkjennings- eller kildestatus er endret. De synlige neste stegene er arbeidsoppgaver, ikke registrerte vedtak eller godkjenninger.

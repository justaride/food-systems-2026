NCH er moderprogrammet over Food TG. Det organiserer **6 transisjonsgrupper**:

1. Bygg og anlegg
2. Tekstil
3. **Mat og bioøkonomi** ← Food TG
4. Plast
5. Elektronikk
6. Tjenester og deling

Programmet utvider seg til **Baltikum** via Baltic Circular Hotspot (Riga, Q1 2027), med
NCM Latvia som regionalt knutepunkt og Baltic Circular Gap Report (1.5M NOK) som
første kartleggingsleveranse.

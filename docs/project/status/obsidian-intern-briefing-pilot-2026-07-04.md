# Obsidian kunnskapskart - intern briefing-pilot

## Kort konklusjon

Kartet er klart for en intern briefing-pilot, men ikke som ekstern figur eller ferdig rapport. Bruk piloten til å teste om teamet raskt finner riktig gap, riktig kildevei og riktig stopplinje.

Pilotens beste første tema er **næringsgjenvinning som beslutningsgap**, med actor-gate og maktkart-datareview som støtteflater. Dette gir høy læring uten å åpne nye claims.

## Bruksregel

- Briefingen er intern og skal ikke brukes som ekstern faktastemme.
- Ingen tall, aktørpåstander, personkoblinger eller årsaksspråk løftes ut uten claim-lock og siterbarhetsgate.
- Grafen brukes som navigasjon og samtaleflate, ikke som bevis alene.
- Nye spørsmål fra møtet registreres som backlogg, claim-lock-kandidat, actor-gate eller research-mission.

## 25-minutters pilot

| Minutt | Del | Skjerm/flate | Output |
|---:|---|---|---|
| 0-3 | Startregel | `Food Systems Obsidian/Welcome.md` | Alle skjønner at kartet er intern cockpit, ikke ekstern konklusjon. |
| 3-8 | Navigasjon | HUB-noten og `Innsiktskartet` | Teamet ser forskjellen på arkiv, analyse og maktstruktur. |
| 8-15 | Valgt gap | `Gap-register`, I36 og R14 claim-lock-kandidater | Én prioritert arbeidsretning velges uten overclaim. |
| 15-20 | Relevante aktører | P2.4 actor-gate og maktkartet | Teamet ser hvem som kan avklare data, uten at aktørdata valideres i møtet. |
| 20-25 | Stopplinje og neste PR | Denne briefingen + backloggen | En konkret neste handling velges: source-shortlist, actor-gate eller datareview. |

## Anbefalt møtefortelling

1. "Kartet forteller oss hvor arbeidet ligger, ikke hva som er ferdig bevist."
2. "Næringsgjenvinning er et godt pilottema fordi det kobler gap-register, I36, claim-lock og verdikjeden."
3. "Den modne delen er ikke et stort tall, men selve kontrollgrepet: N/P/K må skilles per strøm og kilde."
4. "Actor-gate viser hvem vi må spørre først, men ingen outreach er utført."
5. "Neste beslutning er hvilken liten lås vi vil åpne: N/P/K source-shortlist, G1 for actor-gate eller datareview av parkerte I27+-noder."

## Trygg språkpakke

Kan sies internt:

- "Kartet peker på næringsgjenvinning som et prioritert beslutningsgap."
- "P2.2 gjorde gapet tryggere ved å splitte N, P og K per strøm."
- "P2.4 prioriterer hvilke aktørspørsmål som bør avklares først, uten å validere aktørdata."
- "P2.3 holder parkerte I27+-kandidater tilbake til datareview/claim-lock."

Må holdes tilbake eksternt:

- "Norge har dokumentert 25-30 % næringsstoffgap."
- "Andelslandbruk har et aktivt 2026-tall basert på 2023-listen."
- "Maktkartet beviser kontroll, intensjon eller samordning."
- "Parkerte I27+-kandidater er nye innsikter."

## Neste beslutning etter pilot

Velg én av disse som neste PR etter intern gjennomgang:

| Valg | Når riktig | Output |
|---|---|---|
| N/P/K source-shortlist | Teamet vil gjøre P2.2 mer claim-lockbart. | Primærkildekø per strøm og næringsstoff. |
| G1 actor-gate | Teamet vil avklare aktørdata før ny figur. | Godkjent eller avvist outreach-pakke for D2 først. |
| I27+ datareview | Teamet vil styrke maktkartet før møtefigur. | Én parkert kandidat løftes eller avvises med metodegate. |

- Ikke sende actor-gate-spørsmål.
- Ikke generer nye I-noder.
- Ikke behandle intern beslutningsverdi som publiserbarhet.

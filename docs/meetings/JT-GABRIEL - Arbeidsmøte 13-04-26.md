## 3. Food Systems — Fokusområder (JT tenker høyt)

### Sirkularitet må defineres
- Kan ikke si «alt om mat er interessant»
- Sirkularitet i mat = redusere **klima**, **naturavtrykk** og **ressursusikkerhet**
- Definere prinsipper: hvor kan man lage looper, gjenbruke ressurser, redusere tap?

### Identifiserte hull og temaer

| Tema | Beskrivelse |
|---|---|
| **Importavhengighet** | Stor import til NO/FI/SE. Hva kan erstattes lokalt/nordisk? |
| **Regenerativt landbruk** | 5% økologisk i Norge. Forskjell NO/SE/DK. Potensial for mer gjenbruk av ressurser i landbruk |
| **Matsvinn og avfall** | Tap i hele kjeden: produksjon → prosessering → grossist → retail → forbruk. Biogass, kompost, grønn pose |
| **Alternativt fôr** | Soya-import → fiskefôr → avfall. Volare (Finland): soldatfluer → høyverdig protein fra matavfall. Axe Foundation (Sverige): bærekraftig oppdrettsfôr fra blandingsprotein |
| **Direktehandel** | Restauranter som handler direkte fra lokale produsenter. Sørlandet-eksempel: danske poteter velges over norske pga handelsmønstre |
| **Alger og spillvarme** | CO2 + spillvarme fra industri → algeproduksjon → både drivstoff og fôr |
| **Fiskeslam og oppdrettsavfall** | Oppdrett i stor skala = gigantisk ubrukt ressurs. Samle møkk fra oppdrett for gjenbruk |
| **Akademia → skala-gap** | NMBU 10-års prosjekt på alternativt fôr (gran, etc.) — ingen kommersialisering. Masteroppgaver og doktorgrader som ikke når videre |
| **Politikk og virkemidler** | Selvforsyning, kortreist mat, mindre svinn — politikken for bærekraftig/sirkulær mat må kartlegges |

### Selvforsyning
- Norge ville vært ~100% selvforsynt om fiskeeksport ble regnet inn
- 97% av oppdrettsfisk eksporteres
- Produksjonen ville stoppet uten eksportmarkedet

## 4. Verdikjedestruktur — ønsket kartlegging

```
Import ──┐
          ├──→ Prosessering → Grossist ──→ Retail ──→ Privat ──→ Avfall (biogass, dyrefôr, kompost)
Domestic ─┘                              ├──→ HORECA
                                         └──→ Eksport

Tap/svinn skjer i ALLE ledd: produksjon, prosessering, grossist, retail, forbruk
```

**Per nordisk land kartlegge:**
- Volumer gjennom verdikjeden
- Klimaavtrykk per ledd
- Naturavtrykk per ledd
- Sårbarhet / importavhengighet
- Eksisterende sirkularitetslooper (%)
- Potensial for nye looper

**JT:** «Hvis vi skal sette foten ned et sted, er det verdikjedestrukturen — hvor maten flyter og hvor den bare blir utkastet.»

## Spenninger og observasjoner

- **Bredde vs. fokus:** Gabriel har bygget bredt underlag, men JT og Cathrine (fra forrige møte) er tydelige på at det nå må spisses. «Vi kan ikke bare se på matsystemet.»
- **Akademia-gapet:** Mye forskning produseres men kommersialiseres ikke. Fôrselskaper vil ikke ha alternativer før de kan konkurrere med soja på pris.
- **Skala er hullet:** Mange jobber med sirkulære løsninger i liten skala. Utfordringen er å skalere — ikke å finne ideer.
- **Politikk som forutsetning:** Virkemidler for bærekraftig mat må kartlegges — uten politisk rammeverk endres ikke atferd.

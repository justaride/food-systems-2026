# Prioritert masterlogg: Offentlige rapporter om matsystemer, dagligvaremakt, selvforsyning og matsikkerhet (2010–2026)

**Utarbeidet:** Mars 2026 | **Omfang:** Norge og Norden | **Kilde:** Regjeringen.no, Stortinget.no, tilsynsorganer, ekspertutvalg

***

## Om loggen

Loggen dekker norske og nordiske offentlige dokumenter som er direkte relevante for analyse av matsystemer, dagligvaremakt, selvforsyning, matsikkerhet, matsvinn og konkurranseregulering. Hvert dokument er klassifisert etter én eller flere **prosjektakser**:

| Akse | Tema |
|------|------|
| **A** | Matsystemer, matpolitikk og verdikjede |
| **B** | Dagligvaremakt, konkurranse og handelsskikk |
| **C** | Selvforsyning, landbrukspolitikk og jordbruk |
| **D** | Matsvinn og matreduksjon |
| **E** | Folkehelse, kosthold og matforbruk |
| **F** | Matsikkerhet, forsyningsberedskap og krig/krise |
| **G** | Nordisk samarbeid og komparativ politikk |

Prioriteringsrekkefølge: **Høy** = grunnlagsdokument eller politisk styrende, **Middels** = sektoriell rapport eller oppfølgingsdokument, **Lav** = supplerende analyse.

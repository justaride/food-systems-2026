# Evidenspakke: nordisk prosjektlandskap 2026-08-10

Dette området bevarer et reproduserbart manifest og kildeavgrensede analysenotater for breddepasset. Det er ikke et rådataarkiv.

- `verified-source-manifest-2026-08-10.jsonl` genereres av `npm run landscape:report` og peker til offentlig kontrollerte sider, eksakte lokatorer, inntaksstatus og rettighetsstatus.
- `qualitative-source-notes-2026-08-10.md` skiller dokumentert prosjektbeskrivelse, prosjekt-/eierrapportering, intern analyse og menneskeport.
- Rå PDF-er, intervjuer, workshopmateriale og tradisjonell kunnskap lagres ikke her.
- Tom `localPath` og `fileHash` betyr at bare URL, metadata og lokator er registrert. Det betyr ikke at innhold er anskaffet eller klarert for gjenbruk.
- Eventuelle senere tekstuttrekk må ha lovlig grunnlag, eksakt sidetall/avsnitt, SHA-256, lisens/rettighetsstatus og claimkobling før review.

Completion-registeret er fortsatt den kanoniske statusflaten for kilde-, menneske- og publiseringsporter.

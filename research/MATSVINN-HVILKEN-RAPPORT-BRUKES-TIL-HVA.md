# Matsvinn: Hvilken rapport brukes til hva?

Kortversjon for arbeid i prosjektet. Dette er den praktiske oversikten over hvilken kilde som brukes til hvilket spørsmål i verdikjeden.

## Hvis du skal svare på ett bestemt spørsmål

| Spørsmål | Bruk denne kilden først | Hvorfor |
|---|---|---|
| Hva er det samlede bildet for hele verdikjeden i Norge? | `bransjeavtalen-hovedrapport-2020.pdf` | Dette er hovedrapporten som samler hele kjeden i én nasjonal status |
| Hva vet vi om matsvinn i jordbruket / primærleddet? | `landbruksdirektoratet-matsvinn-i-jordbrukssektoren-2023-rapport-52-2024.pdf` | Dette er den sentrale sektorrapporten for jordbruket |
| Hva vet vi om matsvinn i sjømatnæringen? | `sintef-ocean-matsvinn-i-sjomatindustrien-2020.pdf` | Dette er sektorrapporten for sjømatindustrien |
| Hva vet vi om matindustri, grossist, dagligvare, servering, offentlig sektor og husholdning? | `norsus-matvett-sektorrapport-matbransjen-offentlig-sektor-husholdningsleddet-or36-21.pdf` | Dette er hovedkilden for resten av kjeden utenom jordbruk og sjømat |
| Hvilken rapport bruker vi for tiltak, virkemidler og lovspor? | `matsvinnutvalget-2024.pdf` | Denne brukes når spørsmålet er hva som må gjøres, ikke bare hvor mye som går tapt |
| Hvilken rapport bruker vi for definisjoner og metode i jordbruket? | `landbruksdirektoratet-utvikling-av-matsvinnstatistikk-i-jordbrukssektoren-2019.pdf` | Metodegrunnlag for jordbrukssporet |
| Hvilken rapport bruker vi for metode i korn og grønt? | `landbruksdirektoratet-utvikling-av-matsvinnstatistikk-i-korn-og-grontsektoren-2020.pdf` | Metodedypdykk der datagrunnlaget er mest krevende |
| Hvilken kilde bruker vi når spørsmålet er hva som skjer etter at maten blir avfall? | `SSB`-kildene | De dekker biogass, kompostering, forbrenning og annen avfallsbehandling |
| Hvilken kilde bruker vi for bred matsystemkontekst, ikke bare matsvinn? | `baerekraft-i-det-norske-matsystemet-2024.pdf` og `lmd-arbeid-med-baerekraftige-matsystemer-2024.pdf` | De setter matsvinn inn i en større matsystem- og politikkramme |

## Anbefalt standardbruk i prosjektet

| Tema | Standardkilde |
|---|---|
| Hele verdikjeden samlet | `bransjeavtalen-hovedrapport-2020.pdf` |
| Primærledd / jordbruk | `landbruksdirektoratet-matsvinn-i-jordbrukssektoren-2023-rapport-52-2024.pdf` |
| Sjømat | `sintef-ocean-matsvinn-i-sjomatindustrien-2020.pdf` |
| Industri, handel, servering, offentlig sektor, husholdning | `norsus-matvett-sektorrapport-matbransjen-offentlig-sektor-husholdningsleddet-or36-21.pdf` |
| Tiltak og virkemidler | `matsvinnutvalget-2024.pdf` |
| Metode og definisjoner | Landbruksdirektoratets metode-rapporter fra 2019 og 2020 |
| Etter verdikjeden: avfall, biogass, kompost | `SSB`-statistikkene |

## Viktige avklaringer

- `OR.36.21` og `OR.48.21` er ikke samme dokument.
- `OR.36.21` er den riktige sektorrapporten for matbransjen, offentlig sektor og husholdningsleddet i hovedrapport-sporet.
- `OR.48.21` er en egen kartleggingsrapport som er nyttig, men den skal ikke brukes som erstatning for sektorrapporten.
- Når du trenger “ett tall for Norge”, start med hovedrapporten.
- Når du trenger “hvor i kjeden skjer dette?”, gå til sektorrapporten for riktig ledd.
- Når du trenger “hva skjer med avfallet etterpå?”, bruk `SSB`, ikke hovedrapporten alene.

## Les dette først hvis du har 2 minutter

1. Start med hovedrapporten for totalbildet.
2. Gå så til jordbruk, sjømat eller OR.36.21 avhengig av ledd.
3. Bruk Matsvinnutvalget når spørsmålet gjelder tiltak, lov eller virkemidler.
4. Bruk SSB når spørsmålet gjelder biogass, kompost, forbrenning eller avfallsbehandling.

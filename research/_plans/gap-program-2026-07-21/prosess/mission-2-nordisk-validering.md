**Dato:** 2026-07-21

**Mottakere:** Michel Bajuk (Cradlenet, SE) · Betina Simonsen (Lifestyle & Design Cluster, DK). Utvid til FI/IS-kontakt hvis tilgjengelig.

med kontrollerte primærkilder, år/scope, foreløpig tolkning og claim-grense.

## 3. Responsformat → import

Når tabellen kommer tilbake:

- **Bekreftet rad** → `validation_status = partner_confirmed`, `validated_by = partnerens navn`, dato. Tolkningen kan nå brukes som partnervalidert i §4.
- **Korrigert rad** → erstatt vår tolkning med partnerens; `validation_status = partner_corrected`; behold vår opprinnelige som historikk.
- **Ubesvart rad** → forblir `under_validation`; **kan ikke** presenteres som nordisk konklusjon (stopplinje WP-10).
- **Kommentar uten bekreftelse** → `partner_note`, brukes som kvalitativ kontekst, ikke som validering.

Importeres med samme mottakslogg-disiplin som alt annet: partner-svar → mottakslogg → review → base med `validated_by`-proveniens.

# Digitaliserer norsk matproduksjon — Smart landbruk og grønn innovasjon

**Forfatter(e):** NMBU Bærekraftsarena
**Institusjon:** Norges miljø- og biovitenskapelige universitet (NMBU)
**År:** 2024
**Type:** report
**URL:** https://www.nmbu.no/forskning/prosjekter/nmbu-baerekraftsarena-smart-landbruk-og-gronn-innovasjon

## Sammendrag

NMBUs bærekraftsarena for smart landbruk og grønn innovasjon er et tverrfaglig forskningsprosjekt som undersøker hvordan digitalisering og presisjonsteknologi kan gjøre norsk matproduksjon mer bærekraftig og effektiv. Prosjektet samler kompetanse fra alle NMBUs syv fakulteter og arbeider med partnere fra ulike sektorer.

Forskningen omfatter bruk av sensorer, droner, satellittdata og maskinlæring for å optimalisere gjødsling, plantevern og vanning. Målet er å produsere mer mat med færre ressurser og renere energi, tilpasset norske forhold med korte vekstsesonger, varierende klima og spredt arealbruk.

## Nøkkelfunn

- Presisjonsjordbruk kan redusere gjødselforbruk med 15-30 % uten produksjonstap
- Droner og satellittovervåking gir bedre beslutningsgrunnlag for norske bønder
- Maskinlæring forbedrer prognoser for avlinger og sykdomsangrep
- Automatisering kan kompensere for mangel på arbeidskraft i distriktsjordbruket
- Digitalisering krever investeringer i infrastruktur og kompetanse som kan forsterke forskjeller mellom store og små bruk

# R13-LAND-002 - ownership edge ledger PCQ control artifact

**Dato:** 2026-06-25
**Status:** PCQ-only, ikke claim-lock
**Kildegrunnlag:** `research/external/r13/R13-LAND-002-vertikal-integrasjon.md`, Menon/NFD, Konkurransetilsynet, årsrapporter og registerlokatorer
**Bruksregel:** Intern kontroll. Ikke figur, deck, whitepaper eller ekstern claim.

## Kort dom

Vertikale koblinger kan føres som datert struktur- og ownership-edge ledger. De kan ikke alene brukes som bevis for kartell, operativ kontroll, tilgangsnekt eller intensjon. Brreg-mal-URL med `{orgnr}` er ikke kildeklar før hver rad har orgnummer-spesifikt kall eller annen datert eierkilde.

## Kontrollert intern formulering

- Norsk dagligvare og sjømat har dokumenterbare struktur- og eierkoblinger per datert kilde.
- Edge-ledgeren skal vise kilde, dato, eier-/rollefelt og caveat per kobling.
- Private avtaler, franchisevilkår og tilgangsnekt skal holdes utenfor desk-claim.

## Fortsatt ikke claim-lock

| Mangler | Hvorfor det stopper claim/figur |
|---|---|
| Orgnummer-spesifikke Brreg-kall | Mal-URL kan ikke brukes som eierkilde. |
| REMA Distribusjon parent/share | Struktur er beskrevet, men eierprosent må festes. |
| BAMA nyeste shareholder table | Eldre/sekundære prosenter må kontrolleres mot datert note. |
| Franchise- og kontrollvilkår | Private vilkår kan ikke utledes fra struktur alene. |
